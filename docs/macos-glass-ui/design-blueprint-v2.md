# Aggregate macOS 全功能设计蓝图 v2

> 日期：2026-11-19
> 状态：本轮实现的统一设计基准
> 范围：macOS Flutter App；不扩展到 Android 或其他平台

## 1. 目的与依据

之前的 HTML 预览只展示了设置页和 MCP 样例，与软件里的音乐、CLI、连接管理、活动、Host、调用流程及各种弹窗不是同一套界面，因此预览不能代表最终产品。本蓝图先覆盖完整功能，再由 Flutter 生产页面和共享组件落地。以后视觉验收截图直接来自生产页面的 macOS Profile 构建；不再用独立 HTML 原型充当实现效果。

依据按以下顺序处理：

1. UI-0 行为冻结及现有业务代码：决定操作、数据、权限、确认、键盘和运行状态，不能因改版改变。
2. 本文件：决定 macOS 的导航、页面布局、组件层级、材质和状态表现。
3. 用户喜欢的明暗切换控件：决定玻璃触感、柔和点阵、暖色边缘光与整体背景基调。原始控件继续使用其实时拖动和太阳/月亮内部变化。
4. [Glass Light Toggle](https://experiments.thisiswhitespace.com/glass-light-toggle)：只作为原主题控件视觉与手势的参考，不代表 Aggregate 的其他页面布局。
5. revision 5 浏览器稿：保留为历史实验资料；其中的页面布局、HTML 材质替身、样例内容不作为新界面的验收基准。

## 2. 设计方向

### 温润、克制、可操作的玻璃工作台

- 视觉重心是用户手里的玻璃明暗切换控件：乳白或烟灰玻璃面、可辨的内外边缘、柔软落影、有限的暖色掠光，以及细而清楚的圆点图案。
- 信息区共享同一张全窗背景。只用轻微凹入、局部提亮和发丝分隔表达层次，不把每段内容都装进独立发光卡片。
- 高光只帮助定位当前选择、主要操作或正在变化的状态；静止内容不持续闪烁。文本和状态标记依靠形状、位置、标签与颜色共同表达。
- 运行、刷新、搜索等图案保持同一圆点栅格。圆点边缘柔和、大小和间距一致，形状仍要一眼可辨，不能变成模糊的实线图标。
- 产品是中文 macOS 工具。使用系统中文字体与系统拉丁字体，不引入网页展示字体或落地页式 Hero/CTA 结构。

## 3. 全局材质与组件规则

### 3.1 背景与色彩

全窗背景始终由主题切换使用的同一 GlassScene 绘制，并共用同一 daylight/切换进度、颗粒坐标和刷新生命周期。页面不能再铺一层不透明灰色底板，也不单独给开关预览框加另一种底色。这样开关周围的暖光和窗体背景连续，明暗切换时也不会分成两套场景。

以下颜色沿用当前 GlassDesignTokens，用于文字、边线、局部玻璃表面和状态色；背景仍以共享 GlassScene 的实际输出为准。

| 语义 | 浅色 | 深色 | 使用位置 |
| --- | --- | --- | --- |
| 主文字 | #27272F | #EFEFF3 | 标题、正文、主要标签 |
| 次级文字 | #656571 | #B8BAC5 | 说明、元信息 |
| 玻璃表面 | #FBFBFC | #292B32 | 选中项、浮层、按钮面 |
| 内凹面 | #D4D4DC | #111216 | 输入区、代码/结果容器 |
| 细分隔线 | #C9C9D2 | #35363E | 列表分组、区域边界 |
| 玻璃暖光 | #B06520 | #FFD29B | 点缀边缘与交互响应，不作大面积底色 |
| 成功状态 | #35735B | #A2D6BC | 连接、运行成功等真实状态 |
| 危险状态 | #A24640 | #F2A09D | 删除、撤销等危险操作 |

浅深主题的材质参数沿用 token 与主题 shader 的校准结果，不为页面截图临时调色。

### 3.2 字体、空间与窗口

- 字体：系统 UI 字体；简体中文由 macOS 系统中文字体回退，数字和英文跟随 San Francisco。
- 基础间距按 8pt 节奏：页面边距 28–32pt；内容组间距 24pt；行内间距 8–12pt；表格/列表行至少 44pt。
- 页面标题 24–28pt，分区标题 16–18pt，正文 13–15pt，辅助信息至少 12pt。长名称优先换行或显示完整提示，不截掉操作对象。
- 窗口宽度 ≥ 1100pt 时使用导航栏、能力目录、详情三者清晰分区；760–1099pt 时缩窄目录并让内容区顺序排列；小于 760pt 时沿用可访问的侧栏抽屉，页面操作仍能找到。不得为填满宽屏而拉长表单输入框或按钮间距。
- 滚动区域各自承担明确内容，顶部标题/工具栏保持稳定；音乐迷你播放器由 `Scaffold.bottomNavigationBar` 固定在窗口底部，横跨侧栏与主区并由布局预留高度。

### 3.3 操作控件

| 类别 | 目标尺寸 | 规则 |
| --- | --- | --- |
| 主要操作 | 高 50–54pt | 每个当前任务只设一个主操作；文字与点阵图案成组；位置贴近其表单或结果 |
| 次要操作 | 高 40–44pt | 与主操作同材质，减弱暖光强度，不降文字清晰度 |
| 图标操作 | 42–46pt 方形 | 有可访问名称与工具提示；命中范围不小于视觉面 |
| 选择/分段项 | 高至少 40pt | 选中态有玻璃凹凸、形状或边缘反馈，不依赖颜色单独区分 |
| 危险操作 | 高度同次要操作 | 使用危险状态色，远离常用提交位置；二次确认保持现状 |
| 忙碌/禁用 | 不改变布局 | 由业务状态决定；图标动画停止或降为静态；语义和禁用原因保留 |

所有新按钮共享 9×9 点阵绘制器、材质层和单一动效时钟。运行、刷新、搜索沿用用户给出的 96dp 图案轮廓与 25/25/21 个亮点，用圆角点阵呈现，不换成填充线性图标。静置动画低幅度、节奏稳定；按下反馈短促且不遮挡图形；hover、focus、selected、busy、disabled、danger 每种状态保持一套层级。系统“减少动态效果”时停止装饰性运动，点击仍立即执行原动作。

**明暗切换控件的行为冻结：**保留实时任意拖动、坐标到主题进度的映射、阈值、提交时机、回调、太阳/月亮内部点阵变化、折射与光效时序、语义和辅助功能标签。设计稿可以调整外围尺寸和位置；不能以固定帧序列替代实时控件，也不能用新按钮重做其手势。

- macOS 桌面保留连接优先导航。侧栏宽 240pt；连接名称与在线/离线状态放在同一行；“添加”贴近连接列表。所有功能、管理连接、活动和设置组成次级导航组。

- 首次启动没有连接时，主区提供 CLI、MCP 两个添加入口及一句用途说明；添加成功后打开新连接首页。
- 快捷键原样保留：⌘K 搜索、⌘↵ 运行当前功能、Escape 返回/关闭当前层；模态层继续隔离后台快捷键。

## 5. 全功能页面蓝图

### 5.1 连接首页

首页由连接展示元数据决定，不由连接名称猜测。每种连接只出现适合它的任务内容。

| 类型 | 页面结构 | 用户操作顺序 |
| --- | --- | --- |
| 音乐连接 | 当前歌曲、状态和播放控件在首屏；搜索及结果占主要内容区。界面不展示可浏览的队列明细；队列长度和当前位置只用于判断前后曲是否可用。入队动作仅在连接提供 `music.queueAdd` 时出现，账号入口仅在 Runtime 提供可选 `ConnectionAccountPort` 时出现 | 搜索 → 查看可播放结果 → 播放；连接提供入队能力时可加入下一首 |
| 普通 CLI | 标题与连接状态；约 260pt 的命令/动作目录在左，已选命令说明和参数在右；主运行按钮紧跟参数；终端/结果紧邻运行区 | 选命令 → 填参数 → 确认必要权限 → 运行 → 查看输出 |
| MCP | 工具、资源、资源模板、提示按类别分组；约 260pt 的左侧目录显示名称和类型，右侧显示已选项说明、输入参数与结果 | 选类别/项目 → 填参数或查看内容 → 运行/读取 → 查看结果 |

空连接页突出“添加连接”。连接加载/刷新、离线、暂时不可用和加载失败使用对应真实状态，并提供原有重试入口；不出现假数据。

### 5.2 所有功能与搜索

    标题「所有功能」                         [＋ 添加连接]
    [搜索名称、说明、来源 ……………… ⌘K]
    [全部] [CLI] [MCP 工具] [资源] [提示]       收藏/最近
    ┌──────────── 功能目录 ─────────────┬──── 当前功能 ──────────┐
    │ 名称 + 简短说明                    │ 参数 / 权限提示          │
    │ 来源连接 + 功能类型                 │ [运行]                  │
    │ 收藏、可用状态                     │ 最近结果 / 结果操作      │
    └──────────────────────────────────┴────────────────────────┘

- macOS 内容宽度 ≥ 760pt 时目录和详情并排：目录占内容宽度约 34%，限制在 220–360pt，目录独立滚动；详情占剩余空间。页标题、搜索和筛选固定在两列上方。目录行使用名称、短权限/类型提示、单独收藏按钮，选中项只强调当前目标。
- 页内搜索是全局搜索的唯一可见输入框；右上工具栏搜索入口仅在其他页面出现。按 ⌘K 时先切到工作台，再将焦点放入这个输入框。
- 选中目录行后在右侧复用生产 `CapabilityRunPage` 的嵌入态，展示来源/执行端/权限、参数、运行操作与结果；从连接页和活动页打开能力的既有路由仍保留。宽度不足时只显示目录，选中功能进入原完整运行页。页面局部筛选顺序固定为全部、CLI、MCP 工具、资源、提示。
- 目录区域内依次是收藏、最近使用、全部功能；搜索或筛选时去掉不相关分组，计数对应当前结果。收藏按钮不触发行选择。
- 搜索、类型筛选、收藏、最近使用、来源和连接状态保留；空结果允许清空搜索/筛选，错误状态保留重试。
- 桌面选中功能后在右侧显示详情和参数，不强制在目录和独立运行页之间来回切换；空间不足时按“目录 → 参数 → 结果”顺序垂直显示。
- 搜索列表保持可扫读：名称最醒目，说明次之，连接和能力类型作为定位信息。收藏为独立操作，不和打开功能争抢命中区域。

### 5.3 参数、执行、权限和结果

- 参数标签始终在输入框外部可见；必填、默认值、校验和 schema 说明沿用现有内容。短参数在宽屏并排，长文本/代码参数占满可用宽度。
- 主运行操作放在最后一个相关参数之后，并显示适用的 ⌘↵。执行状态来自 Runtime 事件流：排队、运行、取消中、完成、失败和结果待确认分别表达，不凭装饰动画推断结果。
- 运行确认/权限说明位于实际动作之前，明确连接与将交付给执行端的输入；批准/拒绝、可信范围、每会话授权和再次确认规则保持现状。
- 结果区域与运行按钮相邻或紧随其下，展示状态、摘要/原始输出、复制、文件预览/在访达中显示、恢复检查与错误详情。无内容时不显示一个看似可复制的按钮。
- 取消只调用现有 cancel；失败可按原规则重试；结果不确定时先查询活动状态，不自动重放命令。终端保持真实输入、尺寸、中断、选择/复制和会话生命周期。

### 5.4 连接管理与配置

- 左侧连接列表用于选择；右侧详情依次展示连接身份、运行状态、能力数量、检查/诊断结果和配置操作。
- 添加向导按连接类型逐步填写：本地 CLI / stdio MCP / HTTP MCP 保留各自字段、路径选择、环境变量、认证、连接测试与保存条件。每步在标题下显示当前步骤；取消、返回与关闭行为不改变。
- 目标选择器清楚区分本机与已配对 Mac；程序查找、路径选择、未匹配/无权限、连接测试与测试报告放在当前步骤内，失败时保留表单值。
- 动作编辑器保留原始 JSON manifest 编辑、导入/导出、动作选择与 JSON 参数检查；“检查并预览参数”只检查最终参数数组，不运行命令。错误贴近输入区；测试输出不误作正式运行记录；保存、取消和删除确认保持现有边界。
- 重新排序、刷新、移除连接、查看详情和诊断有明确分区。移除等危险操作与主要连接操作分开并再次确认。

### 5.5 活动记录

- 顶部仅按运行状态筛选：全部、成功、失败、取消、超时、运行中、结果待确认。列表项显示能力、发生时间和状态；连接来源在详情区显示。
- 详情显示能力、来源、状态、时间、运行 ID，并明确参数与结果正文未写入活动记录。仍可取消的运行显示“取消运行”；运行中或结果未知时显示“查看运行”，其他终态显示“重新打开功能”；“复制诊断”只复制运行 ID、状态和时间，不添加结果重试动作。
- 空记录、筛选无匹配、加载失败和清空历史分别使用不同状态。清空按钮放在本机数据/危险操作区并走现有确认流程。

### 5.6 设置与 Mac Host

设置采用左侧设置类别导航、右侧单一连续内容区：

    设置 · 让材质、光线和工作方式保持一致
    ┌──────────── 类别 176pt ───────────┬──────── 连续内容区 ───────┐
    │  ◈ 外观                         │ 外观 · 当前模式           │
    │  ▧ Mac Host                     │                          │
    │  ⌘ 快捷键                       │                          │
    │  ▤ 本机数据                     │       [玻璃明暗控件]       │
    │                                 │  [跟随 macOS 系统]         │
    └─────────────────────────────────┴──────────────────────────┘

- macOS 设置类别在宽内容区占 176pt，右侧以一条细分隔线连接连续内容；内容不放入独立不透明卡片。内容宽度不足 760pt 时类别控件折到内容上方，顺序仍为外观、Mac Host、快捷键、本机数据。
- 外观区让原始开关成为主视觉：最大宽度 440pt，绘制比例为 0.46；不在开关后增加单独底板，直接透出同一张 GlassScene。说明与“跟随 macOS 系统”操作在开关周围相邻排列，当前主题文字清晰可读。布局只调整开关的外围空间，不改其实时手势和太阳/月亮内部绘制。

1. **外观**：标题区显示当前模式；原切换控件负责在浅/深模式间实时切换，`AppearanceSelector` 的“跟随 macOS 系统”按钮单独调用系统偏好。控件作为视觉主角，背景直接透出共享全窗材质；不额外增加浅/深分段按钮。Mac Host 与其他偏好继续留在各自分区。
2. **Mac Host**：运行状态与地址先出现；启动/停止、邀请二维码/有效期/复制、待处理配对、已配对设备和权限编辑分组展示；只读、本机控制、连接向导、连接管理与外部写入等范围按现有规则呈现。拒绝设备、撤销配对或轮换身份等危险操作与常规控制分开。
3. **快捷键**：快捷键按功能分组显示，名称左对齐、组合键右对齐；保留全部现有绑定和冲突规则。
4. **本机数据**：活动保留时长与说明成组；清空历史使用单独危险区域和原确认流程。

Host 展示始终由真实平台状态提供。没有可用 Host 时显示当前平台说明；预览夹具中的假 Host/设备必须明确标为预览样例，正式界面不伪造运行状态、地址或邀请。

### 5.7 音乐迷你播放器

- 非音乐页有可见播放会话时，在窗口底部显示横跨侧栏与主区的播放器条：左侧为音乐图标、歌曲标题和输出位置/来源/歌手/状态摘要；右侧依次提供满足条件的上一首/播放或暂停/下一首/停止/刷新状态/打开播放器/收起。
- 不增加封面图或进度拖杆；MiniPlayer 只显示 `MusicSession.detail` 返回的详情文本。保持同一个 MusicSession，切页不重建会话；无可见播放内容或输入法打开时按现有逻辑隐藏。
- 音乐账号区域保留账号状态、扫码登录、退出及失败/未知状态；只有支持账号管理的音乐连接显示这些入口，不把它们放到普通 CLI/MCP。当前生产账号流程没有独立的终端登录入口。

### 5.8 对话框、菜单和通用状态

- 连接配置、运行授权、权限选择、动作编辑、删除、设备批准/编辑/撤销等弹窗按其实际领域聚组。标题明确对象，表单宽度适合内容，主操作固定在右下，取消在其左侧。
- 打开弹窗后焦点进入第一项合理输入；关闭后焦点回到触发控件；模态期间背景快捷键不触发运行。
- 加载、空态、错误、无匹配、已断开、忙碌、禁用、成功、失败、已取消、结果待确认使用统一的图标尺寸/标题/说明/操作顺序，但保留各自语义和原操作。

## 6. 不变的行为边界

- Runtime、账号、钥匙串、文件访问、连接配置、权限、安全确认、音乐 session、Host 和活动记录的数据流及回调维持现状。
- 所有键盘快捷键、焦点恢复、文本输入、滚动位置及打开页面的返回栈维持现状。
- 仅移动控件时，原控件保持相同的启用条件、单次激活、busy/cancel 语义、错误恢复和无障碍名称。
- 主题开关严格遵守 §3.3；新的材质按钮不能替换它。

## 7. 实施与视觉验收方式

按共享基础到用户流程分组实施，每组完成后单独检查并提交：

1. 背景、排版、间距和共用玻璃分区；
2. 外壳、连接导航、全局搜索和窄窗结构；
3. 所有功能目录、CLI/MCP 桌面组合和调用结果；
4. 音乐首页、队列、账号面板和迷你播放器；
5. 连接管理、所有配置/编辑/确认弹窗；
6. 活动记录、设置、Mac Host 与危险操作；
7. 浅深色、动态状态、焦点/无障碍与 Profile 性能复核。

视觉稿的唯一有效来源是这些生产 Flutter 页面。每组保存实际 macOS Profile 截图，覆盖浅深色、标准与窄窗、空/加载/错误/操作状态；用源代码中的同一套组件完成截图和上线。测试/fixture 仅按实际覆盖范围记录，不冒充真实 Runtime 或 Host 操作。主题开关逻辑不变的验收同时检查源码差异、现有交互回归和实窗实时拖动。

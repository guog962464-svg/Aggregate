## 全局状态矩阵

| 状态维度 | 设计覆盖 | 实施约束 |
| --- | --- | --- |
| 浅色 / 深色 | 05、12 与同一套玻璃 token | 页面结构和语义一致；颜色、颗粒、边缘光随场景变化；不单独铺底板 |
| 静置 / hover / focus / 按下 | 11，05 的主题开关静置参照 | 图案、光效、按钮尺寸与点击回弹来自同一生产组件；焦点可见；按下不移位 |
| busy / disabled / error / danger | 09–11、23–24 | 业务状态决定启用与反馈；装饰动画不能伪造执行成功、重试或权限变化 |
| Reduce Motion | 11 | 停止非必要装饰运动，保留完整动作与语义 |
| 空连接 / 空目录 / 空历史 / 无搜索结果 | 03、10、18 | 文案和恢复操作贴近对应内容；不可用状态不填入虚构数据 |
| 连接配置 | 07、19、25–27 | 校验、测试、保存和取消沿当前向导顺序；网络/凭据状态不由画板虚构 |
| 运行结果 | 08–10、16、24 | 成功、失败、取消、超时和结果待确认各自使用实际 RunState |
| 设置页结构 | 05、06、15、22 | 四个 section 属于同一连续滚动页，不增加设置分类 rail 或切页状态；只在窄窗下按自然纵向顺序排列 |
| 窄窗口 | 设计稿 §3、§8 | 小于 760 pt 使用现有抽屉导航；列表/详情按导航→列表→详情单列呈现；独立滚动；不压缩参数或让播放器覆盖内容 |
| 键盘与辅助技术 | 设计稿 §7、§8 | 保留原 shortcuts、AX 名称、焦点恢复和确认门槛；图标操作有名称 |

## 页面路径

1. **查找并运行：** 工作台 → 搜索/筛选 → 选择能力 → 填参 → 选择可用执行端 → 必要时授权 → 运行/终端 → 读取实际结果 → 活动记录。
2. **添加连接：** 管理连接 → 添加 → 选择目标 → 选择适配器表单 → 测试 → 按原条件保存 → 打开连接首页。
3. **编辑连接能力：** 管理连接 → 打开动作编辑 → 编辑 JSON → 检查参数 → 保存/取消；检查阶段不运行命令。
4. **管理 Host：** 设置 → Mac Host → 查看状态/生成邀请 → 核对待配对设备 → 编辑全局或逐连接权限；撤销、拒绝、轮换身份走原确认。
5. **使用音乐：** 音乐连接 → 搜索/选择结果 → 共享 MusicSession 播放；播放信息区的“音乐账号”入口按端口能力显隐；切到其他页面后继续用迷你播放器。
6. **查看与清理活动：** 活动 → 状态筛选 → 查看元数据 → 按运行状态取消/重开/复制诊断；清理操作位于本机数据并走原确认。

## 冻结边界

`glass_theme_switch.dart` 及其 simulation/calibration、拖动、回弹、太阳/月亮内部动画、光效和主题提交逻辑不在视觉重设计范围内。画板只定义它周围的空间和共同材质。其余改造只改变视觉，不改变业务回调、Runtime、Host、音乐会话、权限、快捷键或数据持久化。

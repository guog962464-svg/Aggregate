# UI-1：统一背景与材质令牌

> 状态：已完成 · 前置：[UI-0](stage-0-baseline.md)通过 · 后续：[UI-2](stage-2-buttons-and-glyphs.md)

## 目标

先把整个窗口放到主题按钮同一块背景与光照中，再建立公共材质参数，避免每页、每个按钮各做一套玻璃。

## 具体流程

1. 在 macOS 呈现入口启用新设计主题；公共组件只接收令牌和状态，不导入 `dart:io` 或 macOS 实现。其他平台保留现有呈现路径。
2. 在 `app/lib/app/theme.dart` 及公共展示层组织新令牌；本阶段在 `app/lib/widgets/glass/` 新增令牌、全窗背景和原生材质 fixture。
3. 以设计稿 `drawMaterial` 的天空光照和颗粒分布为参考：浅色底部基准从约 `#ccc` 到 `#ececec`，深色从约 `#0a0a0a` 到 `#1f1f1f`，再叠加右上方光照和细颗粒。端点色不是独立面板的纯色填充。
4. 采用全窗口坐标采样背景：侧栏、内容区、外观设置区共享原点和缩放。分组用间距、文字和分隔线组织；需要独立表面的输入框、菜单、弹窗保持清楚层次。
5. 建立玻璃的凹槽、接触阴影、倒角、内部纹理、折射/色散、散射、窄光弧、细颗粒令牌。深色偏冷蓝，浅色偏暖琥珀；危险操作使用克制的警示色并保留文字语义。
6. 创建独立原生 fixture 材质样本，复用原主题控件并展示新按钮目标高度。原控件直接复用；不把设计稿静态图片带入软件当作控件。
7. 对照深浅色、1×/2×、不同窗口尺寸检查背景与光照。本阶段不新增独立动画相位；背景颗粒跟随原主题开关现有时钟，避免颗粒在开关边界重置。其余按钮的共享相位和协调动效由 UI-3 接入。

## 主题区消缝的可行性门

当前 `glass_theme_switch.frag` 以 `screenPoint / viewport` 生成局部天空，最终输出 alpha=1；`_GlassPainter` 传入控件局部尺寸并绘制整个矩形。因此“父层换背景 + 六文件完全不改”不能直接保证无接缝。

1. 先验证父层组合能否在各尺寸、两种外观和换肤过程中满足连续性；不要把单个端点的近似匹配当作已解决。
2. 若存在接缝，只在渲染接线加入可选的窗口场景原点/范围，使原天空与颗粒计算使用相同背景坐标。保留控件自身的局部几何坐标、指针映射、光学公式和实时状态，不用背景坐标替代它们。
3. 默认场景参数继续等效于原局部 viewport，原 oracle、颜色探针和交互回归原值通过；macOS 全窗场景另设明确期望值验证。Android 及未启用新呈现的调用沿用原默认路径。
4. 记录呈现 diff、默认路径与全窗路径的对照图。不能裁去阴影、模糊矩形边缘、覆盖截图或修改粒子/光弧公式掩盖接缝；若限定范围内仍不可行，先记录阻塞并修订实现方案，不把此项写成通过。

## 尺寸与色彩规则

| 项目 | 起始规格 | 核对方式 |
| --- | --- | --- |
| 主操作 | 高 54 个逻辑像素 | 对照参数之后的运行按钮，点击范围与绘制边界分别记录 |
| 次级操作 | 高 40～46 个逻辑像素 | 同一工具组基线、内边距、文字与图案间距一致 |
| 材质放大样本 | 约 96 个逻辑像素高 | 仅用于对照质感，不照搬成全页面按钮大小 |
| 正文/辅助文字 | 沿用 macOS 系统字体，中文回退完整 | 不能为了塞布局而持续缩小文字 |
| 背景 | 中性天空与全窗颗粒 | 不恢复早期蓝灰 Material 色块或独立主题矩形底板 |
| 语义 | 正文、辅助、焦点、选中、禁用、错误分别有令牌 | 在实际叠层背景检查，不只测基础色表 |

上述尺寸使用 Flutter 逻辑像素；纹理源像素和 DPR 是独立参数。容器缩放不能改变命中、焦点或原主题拖动的坐标语义。

- [x] **UI-1.1** macOS Profile 实窗在 800×600、1024×768、1440×900 逻辑内容尺寸下检查深浅背景；移动窗口并逐档缩放后，主题区周围没有可见矩形底板或天空/噪声重置线。
- [x] **UI-1.2** 两种外观的背景与原主题玻璃共用天空坐标和颗粒时钟；灯芯、月亮/太阳内部、光弧与交互模拟保持原样。
- [x] **UI-1.3** 三个模拟/校准文件及 `appearance_selector.dart` SHA 保持不变。渲染接线只新增场景位置/尺寸 uniform；零尺寸默认路径保留原 viewport 公式。主题交互、光学和实时回归通过。
- [x] **UI-1.4** macOS 颜色与尺寸集中在 `GlassDesignTokens`；公共场景与 fixture 使用 Flutter API。MaterialApp 仅在 macOS 包装全窗 scene，Android/Windows 不接入新主题。
- [x] **UI-1.5** 已保存三个逻辑内容尺寸、两种外观的原生 Retina DPR 2× Profile 截图；Widget 测试覆盖 DPR 1×/2× 下保持 800×600 逻辑 viewport。未连接原生 DPR 1× 显示器。

原生 fixture 入口：`cd app && flutter run -d macos --profile --no-pub -t lib/glass_material_fixture_main.dart`。该入口只用于材质/尺寸预览，不在产品导航中注册。最终截图见[阶段验收记录](acceptance-record.md)。

背景与材质的审美结果保留原生同尺寸对照图，由用户视觉复核；编译通过不能替代此项。

# Aggregate macOS 全功能设计稿 v8.0

> **用途：** v8.0 是接下来 macOS UI 实施和逐屏验收的唯一视觉基准，覆盖 27 张画板、用户操作路径、状态矩阵和窄窗规则。此前版本保留作历史记录，不再作为实现依据。
>
> **范围：** macOS。示例数据仅供画板展示；运行、权限、连接、音乐和活动数据始终来自现有 Runtime 与会话。

## 1. 这版要解决什么

v7 已覆盖全部功能，但用户反馈成品仍和预览不一致。复核发现两类根因：静态 SVG 用近似的阴影和表面表达玻璃按钮，实际 Flutter 绘制出来后厚重很多；设置页还把用户参考图中的纵向连续分区改成了独立子导航。v8 先锁定完整视觉与页面结构，再按同一组 token、同一页面状态和 Profile 实窗逐屏实施。设置里的外观、Mac Host、快捷键和本机数据现在是同一条纵向页面，05、06、15、22 是不同滚动位置。

27 张画板仍覆盖真实功能、弹窗和状态；功能模块、操作路径和状态入口见[功能覆盖矩阵](design-draft-v8/feature-coverage.md)。外壳坐标依据 macOS Profile 的 Accessibility bounds；04/18 按真实 `ActivityPage`、`PageState.empty` 与 `MusicMiniPlayer` 布局。目录在[27 张画板目录](design-draft-v8/README.md)。

本稿用生产 `GlassGlyph` 的 9×9 掩码和圆点几何，固定 v8 颜色、表面、阴影与按钮层级。主题控件外观采用生产截图作视觉锚点；SVG 的静态材质画法只是版式说明，不作为最终材质证据。实施验收必须使用同尺寸 Profile 实窗截图；主题开关和业务行为不在修改范围内。

## 2. 设计方向与自我校准

### 设计方案

Aggregate 是每天使用的 Mac 工作台。界面要让人快速找到能力、判断连接和执行目标、填写参数并读懂真实结果。整套材质从用户认可的主题控件提取：银灰雾面场景、乳白玻璃表层、石墨色点阵与只出现在焦点附近的琥珀光。整体不使用冷蓝色 SaaS 配色，也不把每条信息装进同样的圆角卡片。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 场景底色 | `#D9D8D5` → `#DEDDDA` | `#191A1B` → `#222325` | 全窗连续的雾面背景；侧栏、正文、设置和对话框共用坐标与色场 |
| 天光 | `#F3F1EC` | `#333436` | 一处大范围漫反射，不形成可见面板边界 |
| 玻璃表层 | `#F8F7F3` → `#E5E3DE` | `#383A3B` → `#292A2C` | 按钮、输入表面和需要被操作的内容 |
| 主文字 / 次文字 | `#2B2A27` / `#686761` | `#F0EFEB` / `#B4B1AA` | 正文和辅助信息；状态不能只靠颜色表达 |
| 点阵 / 琥珀光 | `#5D574B` / `#FFC66B` | `#DFD5C1` / `#F2BD70` | 圆角点阵与局部暖光；暖光只标记当前动作或焦点 |
| 分隔 / 内凹面 | `#C1BFBA` / `#D0CEC8` | `#41413F` / `#161718` | 组织页面和输入内容，不额外堆叠描边 |

字体只用 macOS 系统字族（中文 PingFang SC、拉丁 SF）；页面标题、区块标题、正文和辅助说明用字号与字重区分。按钮图案保持 Flutter 的 9×9 圆角点阵，尺寸变化只改变整体比例，不挤压点距。

### 页面结构草图

```text
常驻外壳       连接列表与导航 240pt │ 页面标题 / 页面主操作
工作台         页内搜索、筛选与功能列表 │ 当前能力、参数、目标、运行、结果
连接管理       连接列表            │ 当前连接、状态、能力、管理操作
音乐           播放器与设备状态      │ 搜索、结果列表
活动           状态筛选与历史        │ 单次运行元数据和可用操作
设置           外观 → Mac Host → 快捷键 → 本机数据（同一纵向滚动页）
对话框         当前页面的真实背景 + 单张玻璃面板 + 稳定的取消/确认区
```

页面内容以左对齐为主。工作台、连接和活动采用列表/详情双栏；音乐采用播放区/搜索区双栏；设置使用全宽纵向分区，和用户提供的设置参考一致。窗口窄于 760pt 后按导航、列表、详情顺序改为单列，不压缩输入字段。

### 方案复核

初稿里“每个导航都是凸起玻璃胶囊”和“设置四个分类做左侧子导航”虽然复用了圆角材质，却把主题控件当成装饰外观，而没有沿用它所在页面的组织方式。v8 已改成：普通导航降低表面和阴影，当前项才有一条低亮暖边；设置内容连续纵向排列；主操作保持更清楚的体积，次操作弱化反光；按钮的琥珀光缩到局部，避免整块发橙。这样保留按钮质感，同时把视觉重点还给任务和内容。

## 3. 统一窗口网格

所有主画板使用 1360×900 logical pt；边界与生产 macOS Profile 的完整窗口截图相同，不额外添加模拟的黑色桌面边框。截图和画板必须都按逻辑点比较，不按 Retina 像素比较。

| 区域 | 设计值 | 规则 |
| --- | ---: | --- |
| 窗口外形 | x=0, y=0, w=1360, h=900 | 画板不再虚构窗口外黑边；圆角与透明区域按实窗截图核对 |
| 原生标题栏 + Flutter 工具栏 | 32 + 40 = 72 pt | 交通灯和窗口标题属于原生标题栏；全局搜索按钮对齐 Flutter AppBar，分隔线位于 y=72 |
| 侧栏 | 240 pt | 连接条目、主导航、设置和本机状态顺序固定；连接/导航操作使用低亮玻璃面，当前项加强暖边 |
| 正文左缘 | x=280 pt | 侧栏与正文留 40 pt 操作间距 |
| 正文右缘 | x=1308 pt | 保持至少 32 pt 右侧呼吸空间 |
| 标题 | y 基线约 127 pt | 标题和说明成组；页面主操作与其同组，不漂浮在无关区域 |
| 正文常用节奏 | 8 / 16 / 24 / 32 pt | 控件行内 8–12 pt；区块间 24–32 pt |
| 迷你播放器 | x=270, y=812, w=1048, h=58 pt | 固定在主内容区底部；距窗口内沿 14 pt；不跨入侧栏 |
| 全局搜索 | x=976, y=32, w=360, h=40 pt | 右边距 24 pt；使用与生产一致的玻璃操作按钮和 ⌘K 标签；工作台隐藏 |

设置页没有第二层分类栏。05、06、15、22 是同一条全宽纵向设置页在不同滚动位置的画板；设置正文左缘 x=316、右缘 x=1298。05 中主题控件的参考范围为 `(850, 205, 448, 224)`，左侧放模式、说明和“跟随 macOS 系统”操作；下方依次是 Host、快捷键和本机数据区块。其余区块使用细分隔线，不做独立页面切换。

### 常驻外壳

- 主导航顺序：连接列表、所有功能、管理连接、活动、设置、本机工作空间状态。
- 1360×900pt 画板中，连接导航从 x=32 开始，按钮宽 192pt、高 40pt、按钮间距 9pt；主导航宽 192pt、高 38pt、按钮间距 9pt。播放会话可见时，侧栏设置项随 Scaffold 可用高度上移，位置按 Profile AX bounds 校准，不与主内容播放器重叠。
- 全局搜索只在非工作台页的顶栏出现；工作台使用页内唯一搜索框。`⌘K` 在任意页面仍聚焦工作台搜索。
- 连接首页的刷新按钮位于连接标题行右侧；它和顶栏全局搜索是两个真实入口，画板必须同时表达。
- 1360×900pt Profile 中，全局搜索 AX bounds 为 x=976、y=32、360×40pt；窗口内容区从 Flutter AppBar 下方开始。全局搜索画成可点击玻璃按钮，不画成输入框。
- 迷你播放器只在样例明确存在可见音乐会话时展示。1360×900 画板的面板定位为 x=270、y=812、w=1048、h=58 pt，右侧留 26 pt，距窗口内沿底部 14 pt；正文底部预留播放器高度，不覆盖列表、输入框或焦点，侧栏不被播放器覆盖。
- 页面不能因为放不下而缩小正文字号。窄窗按“导航 → 列表 → 详情”的任务顺序切换到单列；不横向挤压参数输入区。

| 组件 | 目标尺寸 | 视觉和交互规则 |
| --- | --- | --- |
| 页面标题 | 24–28 pt | 左对齐，标题和说明相邻；中文换行不裁切 |
| 分区标题 | 16–18 pt | 与所属内容对齐，避免重复说明 |
| 正文 / 辅助文字 | 13–15 / 12–13 pt | 重要信息不只靠颜色；辅助文字保持可读 |
| 次要按钮 | 高 40 pt，圆角 13 pt | 与生产 `secondaryHeight` / radius 一致；轻接触阴影和薄上缘，不做塑料感厚边；静置不持续闪烁 |
| 主操作按钮 | 高 46 pt，圆角 14 pt | 与生产 `primaryHeight` / radius 一致；与参数组相邻，点阵、文字和暖光保持一体 |
| 图标按钮 | 46×46 pt，圆角 14 pt | 点阵居中，命中范围覆盖整个可见表面，提供工具提示和辅助名称 |
| 分段筛选 | 高 32 pt，圆角 10 pt | 状态可读，选中项以玻璃面表达，不改筛选顺序 |
| 导航按钮 | 高 38/40 pt，圆角 11 pt | 普通项是低亮玻璃触面；当前项加一层细暖边，不让整条侧栏都凸起 |
| 活动记录行 | 361×72 pt，圆角 12 pt | 记录名、时间和状态同一操作面；相邻行间隔 11 pt |
| 迷你播放器 | 1048×58 pt（1360×900 画板） | 贴合主内容区；文字在左，46 pt 点阵控件在右，控件间隔 4 pt；音量和播放状态不改 |
| 输入框 | 高 44–48 pt | 可见标签、值/占位、帮助和错误按现有 schema 表达；错误紧邻字段 |
| 结果/终端内容 | 内凹表面 | 状态、输出和可用操作来自真实结果；无结果时不显示假复制操作 |
| 确认面板 | 520–720 pt 宽，按内容定高 | 背景页面匹配入口；取消与确认位置稳定，危险后果清楚；玻璃面克制，避免整窗蒙白 |

### 玻璃层级

- 场景底色是唯一背景：不在设置主题区或侧栏另铺矩形底板；漫反射宽而浅，切换按钮周围没有接缝。
- 主要动作使用完整的柔润玻璃体积、清楚的点阵和按钮角上的一处暖光。次要动作保留薄边缘与短阴影，不复制主按钮的发光强度。
- 普通导航用低亮触面；当前项只加轻微表面和一条细暖边。文字、状态点与图案不因选中跳位。
- 输入和结果使用轻内凹面，只有需要编辑/复制的内容才形成完整面板。信息分区优先靠对齐、留白和细线。
- 按下态将表面压低约 1pt、缩小接触阴影；释放时恢复。不会用明显位移或持续发光模仿真实操作。

### 点阵按钮

运行、刷新和搜索的剪影分别是完整三角、单向圆环、完整镜片和斜柄。三种常用剪影已按用户提供的按钮参照重新定形；其 9×9 掩码与圆角单元几何是固定实现输入。所有图案沿用相同点距与圆点边缘，尺寸可随按钮变化但不能挤点、变形或出现半格错位。

| 动作 | 静置 | 点击 | 业务状态 |
| --- | --- | --- | --- |
| 运行 | 图案稳定，可有很轻的局部光线呼吸 | 玻璃短压、暖光收进图案再回弹 | 只有 Runtime 运行中才保持忙碌反馈；完成/失败由实际结果切换 |
| 刷新 | 环形图案静止 | 单向旋转一次 | 加载期间由实际刷新状态控制，不重复叠加点击动画 |
| 搜索 | 镜片保持清楚，低亮度反射 | 镜片先亮、短柄跟随收拢 | 输入焦点与搜索结果使用原状态 |
| 选择/导航 | 导航项保留很低的玻璃面；当前项加强边缘和一处暖光 | 表面短压，不移动周围布局 | 选中语义与现有选路逻辑相同 |
| 危险操作 | 不做吸引注意的待机动画 | 短压并露出危险边缘 | 原二次确认和执行回调保持 |

单一 `GlassMotion` 时钟负责装饰性动画。Reduce Motion 时使用明确静态态；键盘焦点、禁用原因和辅助名称继续可见。

### 按钮的静置和点击节奏

静置阶段由同一单调时钟采样：每种点阵有自己的低幅扫光/漂移方向，整页不同时闪烁。点击阶段只改变被操作按钮的点阵、边缘光和玻璃压感；动作结束后回到当时的静置相位。下表列出图案当前的动作 profile 与验收外观，时长来自 `GlassMotionAction` 配置；动画不延后或重放业务回调。

| 按钮/图案 | 静置光路 | 点击图案动作 | 时长 |
| --- | --- | --- | ---: |
| 运行 | 微弱横向扫光，形状稳定 | 三角沿播放方向短移并略微放大，点阵扫光增强后回稳 | 160 ms |
| 刷新 | 点阵环绕中心缓慢漂移 | 环形点阵转过一周，同时从中心向外扫光 | 220 ms |
| 搜索 | 光点围绕镜片轻微漂移 | 镜片与短柄作为一个图案轻微放大，扫光增强后回稳 | 160 ms |
| 关闭 | 低幅棋盘式明暗变化 | × 点阵轻微收紧并微转，中心光增强后回稳 | 130 ms |
| 上一首 / 下一首 | 上一首反向、下一首正向横向流动 | 点阵按各自方向短移和扫光，不交换两个按钮的图案方向 | 500 / 480 ms |
| 暂停 / 停止 | 暂停为竖列流动；停止为点位相位变化 | 暂停图案轻微横向收紧；停止图案收窄后恢复 | 560 / 480 ms |
| 添加 | 低幅中心呼吸 | 点阵整体轻微收紧，再回到原剪影 | 540 ms |
| 连接 / 活动 / 设置 | 连接以点位相位变化；活动逐行亮起；设置沿圆周流光 | 连接略微收紧，活动图案纵向舒展；设置图案轻微转动，点阵保持清晰 | 560 / 520 / 640 ms |

所有按钮使用同一玻璃厚度、圆角点阵和光色。动效差异来自图案的扫光方向、收放或旋转；不为某个按钮另造材质。11 号画板展示静置、聚焦和按下外观；完整时长与动作对应以上表格。

## 6. 关键操作路径

1. **找到并运行：** 工作台搜索 → 类型筛选 → 选择功能 → 填参并校验 → 选择有效目标 → 必要时确认权限 → 运行 → 查看真实结果。
2. **建立连接：** 连接管理 → 添加 → 目标选择 → 适配器配置 → 测试 → 仅在现有检查结果允许时保存。
3. **管理设备：** 设置页向下滚到 Mac Host → 查看实际状态 → 生成/复制邀请 → 核对设备后批准 → 按全局/连接范围编辑权限；撤销、拒绝、身份轮换使用原确认。
4. **控制音乐：** 播放页与迷你播放器共享同一会话；按钮显隐由连接能力和当前队列状态决定。
5. **查看活动：** 状态筛选 → 选择记录 → 查看元数据 → 按状态取消、重新打开或复制诊断；清理记录前确认后果。

## 7. 不可修改的行为边界

`glass_theme_switch.dart`、`theme_switch_simulation.dart`、`theme_switch_calibration.dart`、`theme_switch_fitted_calibration.dart` 和主题回调继续冻结。保留实时任意拖动、反向、取消、阈值、回弹、提交时机、偏好同步、太阳/月亮内部形态、折射、光效及其节奏。允许调整外围布局尺寸和间距；不能用固定帧、视频、WebView 或新手势替代原控件。

所有其他按钮改造只影响视觉呈现，不改变已有操作入口、启用条件、快捷键、回调、权限、Runtime、Host 或音乐会话。示例名称、状态、结果和确认码只存在于安全预览数据，不进入生产状态。

## 8. 画板到实现的验收门槛

- 先把设计稿和页面样例锁定，再改对应生产页面。需要改变稿件时，先改稿和对应页面标准，然后再实现。
- 每个主画板使用 1360×900pt macOS Profile 实窗截图并排对照；主列边界、标题基线、表单和操作尺寸误差不超过 4pt。迷你播放器面板与画板位置、宽高误差不超过 2pt。
- 对照全窗背景采样、按钮厚度/边缘/阴影范围/点阵、文字层级、选中状态、焦点、运行状态、空态和实际内容；不能只核对组件名字或外框坐标。
- 生产截图必须来自同尺寸 Flutter Profile 页面。SVG 负责固定版式和内容，不作为材质通过证据；材质验收以 v8 token 和生产主题控件参考为准。
- 每个阶段分别保存：画板 revision、实际 Profile 截图、相关回归记录、模型/窗口逻辑尺寸、浅深主题状态与提交 SHA。
- 设计稿、自动化测试、预览 Runtime、Profile 实窗和用户最终视觉复核是不同证据；未覆盖的页面不得记为通过。
- 窄窗、浅/深主题、键盘焦点、Reduce Motion 和原主题拖动行为在全稿验收阶段逐项核对。

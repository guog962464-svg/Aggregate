# Aggregate macOS 全功能设计稿 v6.2

> **用途：** 这是 UI-8 后续实现的统一视觉和页面基准。先核对全功能画板，再按同一尺寸和状态逐页接入生产 Flutter 页面。v6.2 绑定可复现的预览数据，避免稿件增加 Runtime 中没有的样例能力；v6.1/v6.0 与更早版本保留作历史参考，不再作为本轮页面验收标准。
>
> **范围：** macOS。示例数据仅供画板展示；运行、权限、连接、音乐和活动数据始终来自现有 Runtime 与会话。

## 1. 这版要解决什么

先前设计与实窗在同一页面上出现了可避免的差异：工作台同时画出全局搜索和页内搜索；连接首页没有标出当前连接，也漏掉页面刷新按钮；有些画板的弹窗底图与实际入口页面不同；按钮、列表、标题和输入框的尺寸规则分散在多个文档中。v6 把这些规则收回到一个窗口网格，并为每个真实功能入口指定页面、状态、样例和验收边界。v6.1 统一了列表静置/选中外观和迷你播放器位置、尺寸、按钮组；v6.2 再把页面样例绑定到安全预览 Runtime，修正 CLI 首页多画的两项能力。

完整页面清单在[27 张画板目录](design-draft-v6/README.md)，每张画板均由同目录的生成器输出。画板是布局和内容状态的明确目标；玻璃材质仍以生产 `GlassScene`、主题切换控件和 macOS Profile 实窗截图为准。逐稿验收时按第 9 节选择同一预览入口、连接、能力、主题和页面状态。

## 2. 设计方向

Aggregate 是桌面工作台，核心顺序是：找到功能、确认来源和执行目标、填写参数、执行、读取真实结果。最有辨识度的部分仍是用户认可的太阳/月亮玻璃切换控件：柔润的体积、清楚但不硬的边缘、内凹阴影、克制暖光和圆润点阵。

- 整个窗口共享一张连续的玻璃场景背景。侧栏、正文、弹窗和主题控件不各自铺底色。
- 正文以文字层级、留白和细分隔线组织。卡片只用于可选条目、输入内容、终端、结果或需要被操作的对象。
- 玻璃按钮按层级使用：主操作有短促暖光，次操作保留柔和玻璃边缘，危险操作使用低饱和危险色；不让整页按钮同时发光。
- 所有自绘操作图案共享 9×9 点阵、圆点大小和间距。运行、刷新、搜索各自保留易读剪影；太阳/月亮仍使用现有控件和原始内部变化。
- 静置动效轻微且不改变布局；点击反馈清楚、短促。业务忙碌与成功状态只由真实业务事件驱动。
- 文案使用用户熟悉的动作词；标签、帮助文字、错误和空态说明各自只承担一项任务。

视觉方向搜索得到的是网页营销页、通用 SaaS 配色和不适用于 macOS 原生桌面工具的字体建议。本稿遵循用户指定的切换按钮质感、仓库的 GlassScene/token、macOS 系统字体和实际功能流程，不把这些通用搜索结果写入产品规范。

## 3. 统一窗口网格

所有主画板使用 1360×900 logical pt。截图和画板必须都按逻辑点比较，不按 Retina 像素比较。

| 区域 | 设计值 | 规则 |
| --- | ---: | --- |
| 窗口外形 | x=16, y=16, w=1328, h=868 | 圆角和背景场景边缘来自原生窗口与 `GlassScene` |
| 顶栏 | 42 pt | 保留 macOS 红黄绿控制点和 Aggregate 标题 |
| 侧栏 | 240 pt | 连接、主导航、设置、工作空间状态顺序固定；选中项用同一玻璃材质轻强调 |
| 正文左缘 | x=280 pt | 侧栏与正文留 40 pt 操作间距 |
| 正文右缘 | x=1308 pt | 保持至少 32 pt 右侧呼吸空间 |
| 标题 | y 基线约 127 pt | 标题和说明成组；页面主操作与其同组，不漂浮在无关区域 |
| 正文常用节奏 | 8 / 16 / 24 / 32 pt | 控件行内 8–12 pt；区块间 24–32 pt |
| 迷你播放器 | x=270, y=812, w=1048, h=58 pt | 固定在主内容区底部；距窗口内沿 14 pt；不跨入侧栏 |

### 常驻外壳

- 主导航顺序：连接列表、所有功能、管理连接、活动、设置、本机工作空间状态。
- 全局搜索只在非工作台页的顶栏出现；工作台使用页内唯一搜索框。`⌘K` 在任意页面仍聚焦工作台搜索。
- 连接首页的刷新按钮位于连接标题行右侧；它和顶栏全局搜索是两个真实入口，画板必须同时表达。
- 迷你播放器只在样例明确存在可见音乐会话时展示。1360×900 画板的面板定位为 x=270、y=812、w=1048、h=58 pt，右侧留 26 pt，距窗口内沿底部 14 pt；正文底部预留播放器高度，不覆盖列表、输入框或焦点，侧栏不被播放器覆盖。
- 页面不能因为放不下而缩小正文字号。窄窗按“导航 → 列表 → 详情”的任务顺序切换到单列；不横向挤压参数输入区。

## 4. 组件、尺寸与状态

| 组件 | 目标尺寸 | 视觉和交互规则 |
| --- | --- | --- |
| 页面标题 | 24–28 pt | 左对齐，标题和说明相邻；中文换行不裁切 |
| 分区标题 | 16–18 pt | 与所属内容对齐，避免重复说明 |
| 正文 / 辅助文字 | 13–15 / 12–13 pt | 重要信息不只靠颜色；辅助文字保持可读 |
| 次要按钮 | 高 38–42 pt | 圆润玻璃面、轻阴影、薄上缘；静置不持续闪烁 |
| 主操作按钮 | 高 38–46 pt | 与同组控件相邻；运行图案、文字和暖光保持一体 |
| 图标按钮 | 42–46 pt 方形 | 点阵居中，命中范围覆盖整个可见表面，提供工具提示和辅助名称 |
| 列表项 | 高 48–60 pt | 普通项靠文字、图案和分隔线扫读；仅选中项提升玻璃表面 |
| 迷你播放器 | 1048×58 pt（1360×900 画板） | 贴合主内容区；文字在左，46 pt 点阵控件在右，控件间隔 4 pt |
| 输入框 | 高 44–48 pt | 可见标签、值/占位、帮助和错误按现有 schema 表达；错误紧邻字段 |
| 结果/终端内容 | 内凹表面 | 状态、输出和可用操作来自真实结果；无结果时不显示假复制操作 |
| 确认面板 | 520–720 pt 宽，按内容定高 | 背景页面匹配入口；取消与确认位置稳定，危险后果清楚 |

### 点阵按钮

运行、刷新和搜索的剪影分别是完整三角、单向圆环、完整镜片和斜柄。所有图案沿用相同点距与圆点边缘，尺寸可随按钮变化但不能挤点、变形或出现半格错位。

| 动作 | 静置 | 点击 | 业务状态 |
| --- | --- | --- | --- |
| 运行 | 图案稳定，可有很轻的局部光线呼吸 | 玻璃短压、暖光收进图案再回弹 | 只有 Runtime 运行中才保持忙碌反馈；完成/失败由实际结果切换 |
| 刷新 | 环形图案静止 | 单向旋转一次 | 加载期间由实际刷新状态控制，不重复叠加点击动画 |
| 搜索 | 镜片保持清楚，低亮度反射 | 镜片先亮、短柄跟随收拢 | 输入焦点与搜索结果使用原状态 |
| 选择/导航 | 只有选中项保留低亮边缘 | 表面短压，不移动周围布局 | 选中语义与现有选路逻辑相同 |
| 危险操作 | 不做吸引注意的待机动画 | 短压并露出危险边缘 | 原二次确认和执行回调保持 |

单一 `GlassMotion` 时钟负责装饰性动画。Reduce Motion 时使用明确静态态；键盘焦点、禁用原因和辅助名称继续可见。

## 6. 关键操作路径

1. **找到并运行：** 工作台搜索 → 类型筛选 → 选择功能 → 填参并校验 → 选择有效目标 → 必要时确认权限 → 运行 → 查看真实结果。
2. **建立连接：** 连接管理 → 添加 → 目标选择 → 适配器配置 → 测试 → 仅在现有检查结果允许时保存。
3. **管理设备：** 查看 Host 实际状态 → 生成/复制邀请 → 核对设备后批准 → 按全局/连接范围编辑权限；撤销、拒绝、身份轮换使用原确认。
4. **控制音乐：** 播放页与迷你播放器共享同一会话；按钮显隐由连接能力和当前队列状态决定。
5. **查看活动：** 状态筛选 → 选择记录 → 查看元数据 → 按状态取消、重新打开或复制诊断；清理记录前确认后果。

## 7. 不可修改的行为边界

`glass_theme_switch.dart`、`theme_switch_simulation.dart`、`theme_switch_calibration.dart`、`theme_switch_fitted_calibration.dart` 和主题回调继续冻结。保留实时任意拖动、反向、取消、阈值、回弹、提交时机、偏好同步、太阳/月亮内部形态、折射、光效及其节奏。允许调整外围布局尺寸和间距；不能用固定帧、视频、WebView 或新手势替代原控件。

所有其他按钮改造只影响视觉呈现，不改变已有操作入口、启用条件、快捷键、回调、权限、Runtime、Host 或音乐会话。示例名称、状态、结果和确认码只存在于安全预览数据，不进入生产状态。

## 8. 画板到实现的验收门槛

- 先把设计稿和页面样例锁定，再改对应生产页面。需要改变稿件时，先改稿和对应页面标准，然后再实现。
- 每个主画板使用 1360×900pt macOS Profile 实窗截图并排对照；主列边界、标题基线、表单和操作尺寸误差不超过 4pt。迷你播放器面板与画板位置、宽高误差不超过 2pt。
- 对照全窗背景、按钮厚度/边缘/点阵、文字层级、选中状态、焦点、运行状态、空态和实际内容；不能只核对组件名字。
- 每个阶段分别保存：画板 revision、实际 Profile 截图、相关回归记录、模型/窗口逻辑尺寸、浅深主题状态与提交 SHA。
- 设计稿、自动化测试、预览 Runtime、Profile 实窗和用户最终视觉复核是不同证据；未覆盖的页面不得记为通过。
- 窄窗、浅/深主题、键盘焦点、Reduce Motion 和原主题拖动行为在全稿验收阶段逐项核对。

## 9. 画板样例与预览状态

稿件里的连接名称、能力名称、字段和结果必须能由安全的内存预览重现。逐稿比较前固定 1360×900pt、主题、页面、选中项、筛选和滚动位置；若状态需要样例操作，操作只落在当前预览进程中。

| 画板 | 预览入口与状态 |
| --- | --- |
| 01、02、03、05、12、15、17、18、21、22 | `preview_main.dart` + `createPreviewRuntime()`；Host 面板使用 `Ui6InspectionHost`。连接/能力数量、播放状态与页面内容以该 fixture 实际返回为准。工作台选中 MCP「两个整数相加」；CLI 首页只有「查看 Git 状态」一项；MCP 首页展示一个工具、一个资源和一个提示。 |
| 04 | `ui6_inspection_main.dart --dart-define=UI6_SEED_ACTIVITY=true`，仅内存生成成功、失败和取消记录。 |

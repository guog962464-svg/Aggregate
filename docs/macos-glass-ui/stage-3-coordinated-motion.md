# UI-3：静置、点击与连续操作协调

> 状态：待执行 · 前置：[UI-2](stage-2-buttons-and-glyphs.md)通过 · 后续：[UI-4](stage-4-page-adaptation.md)

## 目标

保持按钮各自的动作特征，使图案、内光、按压和边光连续衔接，避免每次触发都闪回初始帧。

## 具体流程

1. 新按钮使用一个共享单调时间源，各按钮保存稳定的相位偏移。图案姿态、能量、按压和光学采样读取同一帧时间，不分设互不相干的循环。
2. 静置保持低幅度运动：颗粒明暗约 0.84～0.96，细微位移；可按设计约 30 Hz 更新装饰。点击按显示节奏平滑采样，不把每个回调当成固定物理步长。
3. 点击能量采用平滑的 `sin²(πt)` 包络，旋转使用单调 smootherstep 完整旅程。点击叠加在持续的静置相位上，结束后从当前状态回到静置。
4. 重复点击时合并仍在进行的装饰脉冲，不重置姿态或时钟。每次本来允许的业务操作仍按现有规则处理；忙碌/禁用状态继续阻止不允许的提交。
5. 播放/暂停等图案反向切换从当前颗粒位置与 alpha 重新配对，新增颗粒从透明进入；不重建整个按钮或先显示目标端点。
6. hover/focus 仅做小幅光照/alpha 反馈；原设计约 320 ms 的轻反馈与至多 0.15 的能量量级可作起点，不让刷新在悬停时转一整圈。
7. 结合 `TickerMode`、路由/页面可见性、视口和窗口生命周期暂停不可见装饰。后台恢复使用经过的真实时间归位，不积压并补播隐藏期间的每一帧。
8. 系统减少动态效果开启时，停止静置、点击装饰与图案飞散，直接表达稳定语义状态；业务操作仍立即可用。原主题继续自己的既有处理，不套用新按钮的时钟或动作令牌。

## 每类按钮的动作与时长

时长从触发到回归静置，来自当前 revision 5 的运行参数，不采用历史材质板旧文案的分段时长。

| 图案/操作 | 静置 | 点击 | 总时长 |
| --- | --- | --- | --- |
| 运行/播放 | 细光缓慢向前流动 | 内核前推与光照增强，保持三角点阵 | 520 ms |
| 暂停 | 双列交替微亮 | 双列制动、边光归稳 | 560 ms |
| 添加 | 微光向中心汇聚 | 十字聚合后舒展 | 540 ms |
| 刷新 | 沿点阵弧线游光 | 完整顺向旋转后归位，开口清楚 | 680 ms |
| 复制 | 两层细微错光 | 对角折射分离后归位 | 520 ms |
| 保存 | 向底座缓慢流光 | 下沉后稳定 | 580 ms |
| 搜索 | 透镜内部轻扫描 | 轻聚焦并扫过镜心 | 560 ms |
| 打开 | 沿出口轻微流光 | 向上引出后归位 | 560 ms |
| 停止 | 内部缓慢明暗 | 轻收拢与制动 | 480 ms |
| 移除 | 极轻的内缘呼吸 | 下沉并收拢警示光 | 640 ms |
| 连接 | 节点依次微亮 | 节点吸附、连线保持清楚 | 560 ms |
| 允许访问 | 沿护盾内缘传光 | 轻聚合、护盾归稳 | 560 ms |

播放/暂停的图案 morph 单独使用约 **360 ms**；它不等于按钮点击时长，更不等于播放器真实确认耗时。表外图案复用语义动作族，定义后进入同一动作表。

聚合位移以不糊成团为前提：当前中心收缩上限约 15%，复制错位约 0.23 格、保存下沉约 0.55 格、停止横向收拢约 14%。旋转后的点仍使用同一圆角颗粒，不在动作中切换为实心图形。

## 可重复验收

下面测试需可注入时钟和固定输入。数值连续性使用同一事件前后同一时间戳比较，不把正常随时间变化误判为跳变。

- [ ] **UI-3.1** 12 类按钮分别经历 idle→click→idle：触发瞬间的位置/alpha 连续；结束不闪回零帧；图案与光弧使用相同时间戳和能量。
- [ ] **UI-3.2** 检查归一化时间 0、0.25、0.5、0.75、1 的姿态及中间采样：持续运动中颗粒清楚，无倒转回程、糊块或瞬间亮灭。
- [ ] **UI-3.3** 每 100 ms 点击一次、共 10 次：装饰不反复归零；可操作按钮回调次数符合原规则；业务忙碌时没有因动画绕过禁用或重复提交。
- [ ] **UI-3.4** 播放/暂停在 morph 的 100、200、350 ms 反向：从当前点位和 alpha 接续，最终图案与真实会话状态一致，结束后没有遗留颗粒。
- [ ] **UI-3.5** 悬停/焦点只轻反馈；刷新不整圈旋转，离开后不突然熄灭。按下拖出取消不错误执行业务。
- [ ] **UI-3.6** 隐藏页、完全离屏按钮及后台窗口停止自身装饰排帧；监听和图像资源没有累积。恢复时无补播积压或可见闪跳。
- [ ] **UI-3.7** 减少动态效果开启后装饰静止，业务回调/语义状态仍工作；关闭后从稳定相位恢复，不启动重复时钟。
- [ ] **UI-3.8** 以 30/60/120 Hz 和非均匀时间序列采样，在相同经过时间与输入下得到等效姿态；不通过修改原主题固定步进来达到新按钮指标。

## 测试注意

常驻 idle 会持续排帧。新增组件测试和 `app/tool/ui_review_test.dart` 截图必须使用固定时钟/固定相位，或单独冻结装饰并定时 `pump`；不要依赖无期限的 `pumpAndSettle()`。冻结仅用于测试和截图，产品仍保留用户要求的静置动效。

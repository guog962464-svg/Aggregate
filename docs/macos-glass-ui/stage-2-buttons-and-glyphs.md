# UI-2：统一按钮与细腻点阵

> 状态：已完成（2026-11-14）· 前置：[UI-1](stage-1-background-and-tokens.md)通过 · 后续：[UI-3](stage-3-coordinated-motion.md)

## 目标

在 Flutter 建立共用的玻璃按钮和颗粒工厂，所有按钮内部图案具有相同的颗粒质感与清晰度。

## 具体流程

1. 把 UI-0 操作清单映射到主操作、次级按钮、图标按钮、播控、导航、分段选择和危险操作。普通文字链接保持链接语义；原主题控件单独复用，不进入新按钮工厂。
2. 新按钮保留 Flutter 的可访问名称、焦点、键盘激活、禁用和命中语义；将装饰绘制与操作层分开。暴露图案、规格、启用/忙碌/选中状态和回调，避免把 Runtime 对象或权限逻辑塞进材质组件。
3. 新增统一点阵绘制层。所有图案和形变中间态通过同一颗粒工厂，不能让某两个图案走连续轮廓或不同锐化路径。
4. 使用 Profile 原生样本比较 `CustomPainter`、Runtime shader 和纹理缓存。按钮基底只需绘制有限的圆角路径，不采样背景像素；本阶段采用 `CustomPainter`，不为每颗按钮创建 shader 或纹理，也不修改原主题的光学公式。UI-1 的背景场景接线单独审阅。
5. 点阵路径按 57 个 `GlassGlyph` 枚举值惰性创建并缓存；缓存有固定上限，没有图片、GPU shader 或纹理需要释放。尺寸、DPR、外观改变只重新绘制现有几何，静置/点击姿态缓存由 UI-3 定义。
6. 制作 12 个 96 dp 设计尺寸图案与 12 类实际按钮/状态样本；将 `app/lib` 当前 81 个 Material 图标名映射到同一字典。产品页面真实按钮的替换在 UI-4 逐页进行，避免把组件验证与业务接入混在本阶段。
7. 在正常、焦点、悬停、按下、禁用、忙碌、选中和危险状态保存固定相位快照。检验放大样本与实际小按钮，不只看大图。

## 颗粒基准

以下数值来自 revision 5 的 32×32 图案设计坐标，不是每个按钮的实际 dp，也不替换原主题的 17×17 模型：

| 项目 | 设计值 |
| --- | --- |
| 逻辑网格 | 9×9 |
| 图案设计画布 / 原点 | 32×32 / 4 |
| 点中心节距 / 颗粒边长 | 2.7 / 1.9 |
| 颗粒圆角半径 | 0.64 |
| 边缘覆盖过渡 | 0.17 |
| 极弱局部光晕宽度 / alpha | 0.16 / 0.075 |
| 设计稿图案源纹理 | 128×128，设计坐标 4 倍采样 |
| 单颗粒覆盖率缓存 | 设计稿为 32×32 sprite，可在 Flutter 使用等效解析覆盖或缓存 |

这些数值是视觉起点。Flutter 纹理分辨率应结合目标显示大小与 DPR 核验：既不能用低分辨率近邻放大造成硬阶梯，也不能无条件为每个按钮创建大纹理。若实现方式不同，记录相同设计坐标下的等效值与对照证据。

“软润”表现为圆角颗粒、清楚内核、窄柔边和玻璃内部散射。不能靠整体大模糊、缩细图案、降低对比度或把相邻颗粒糊成实心块实现。

## UI-2 实施记录

- `GlassActionButton` 将 Flutter `TextButton` 的语义、键盘与焦点行为同自绘玻璃背景分开；支持主操作、次级、图标、播控、导航、分段与危险样式，并暴露禁用、忙碌、选中状态。
- `GlassGlyphMark` 的核心点与低透明外围散射都来自 9×9 圆角点阵；路径按枚举惰性缓存。运行、刷新、复制、网络和护盾没有连续矢量图标例外。
- macOS 原生 fixture 包含 12 个 96 dp 对照图案、12 类实际按钮/状态以及完整 57 项图案字典；样例无业务回调，并复用原 `GlassThemeSwitch` 切换浅/深外观。
- 应用当前 81 个 `Icons.*` 名称逐一核对，均能映射到 `GlassGlyphCatalog`；生产页面仍保留原图标，UI-4 再将字典逐页接入。
- 实现选型：核心颗粒保留清楚轮廓，外围使用轻微 blur 羽化；按钮面使用渐变、内倒角、接触边、焦点环及随状态变化的上下光弧。没有增加动态循环，动画统一留给 UI-3。
- 对照差异：设计稿的 96 dp 方形按钮有更宽的外部环境光晕和更强折射/色散；Flutter 样本目前使用较克制的单层渐变与边缘光，不采样场景背景，因此不会复现完整折射或 RGB 分离。图案网格、比例、核心点、角圆与状态语义按设计坐标实现。此差异已纳入 UI-2.6 记录，整套界面的最终材质签收由 UI-6 单独完成。

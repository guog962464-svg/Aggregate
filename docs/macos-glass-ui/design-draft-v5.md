# Aggregate macOS 全功能界面设计稿 v5.0

> 当前视觉基准。先按现有功能完成画板，再按画板实现和逐屏验收。v3.8 画板与 v4.1 规范保留作历史记录；本稿和其 24 张画板取代它们作为当前实施依据。
>
> 平台：macOS。产品范围、业务回调和共享 Flutter/Dart 契约不变。所有示例数据仅供预览。

## 1. 设计方向

Aggregate 是管理 CLI、MCP、本机音乐和 Mac Host 的工作台。界面的标志是用户认可的明暗切换按钮：柔润、可触的玻璃体，克制的金色暖光，细圆的点阵图案。整窗背景从该控件所在的连续场景延展；其他控件沿用同一光线、玻璃边缘和阴影，不复制开关本身的尺寸。

主要任务沿着“找到功能 → 看懂目标与权限 → 输入参数 → 执行 → 判断结果”排列。连接目录和记录使用轻分隔线；只有需要编辑、聚焦或表达重要状态时才出现玻璃表面。每个页面保留一处视觉重点，避免把所有内容做成同样大小的卡片。

### 画面结构

```text
└───────────────┴────────────────────────────────────────────────┘
```

## 2. 视觉规范

### 2.1 背景、玻璃和光线

浅色背景沿用主题开关所在的 `GlassScene`：银灰场景带一层很轻的暖光，页面之间不重置背景。深色保持同一光线方向和层次。页面不得再铺另一块大面积独立灰底。

| 语义 | 浅色目标 | 深色目标 | 用途 |
| --- | --- | --- | --- |
| 场景 | `#E6E6E8` 基底，右上扩散至 `#F4F4F6` | `#0A0A0C` 基底，右上扩散至 `#1E2025` | 与 `GlassScene` 着色器方向、颗粒一致；页面不另设底色 |
| 玻璃上缘 | `#FFFFFF`，轻微透底 | `#41434C`，轻微透底 | 按钮和弹窗表面 |
| 玻璃下缘 | `#ECECF0` | `#242630` | 体积和下缘阴影 |
| 主文字 | `#27272F` | `#EFEFF3` | 标题、主要内容 |
| 辅助文字 | `#656571` | `#B8BAC5` | 说明、时间和辅助信息 |
| 局部光色 | 亮色 `GlassDesignTokens.glow`；原开关仍用校准的琥珀光 | `GlassDesignTokens.glow` 蓝紫色 | 焦点与被选择的操作；不把整窗背景染成橙色 |
| 状态色 | 成功 `#35735B`；危险 `#A24640` | 成功 `#A2D6BC`；危险 `#F2A09D` | 必须同时有文字或图案 |

画板的场景色只用于静态预览；生产页面继续使用 `GlassScene`。它从窗口右上方向扩散亮度，叠加轻微颗粒；侧栏、正文、外观页和弹窗沿同一窗口坐标采样，不能局部重置 shader 或再铺整块灰底。表面、文字和状态色统一映射到 `GlassDesignTokens`。暖光集中在控件右上侧；整窗不加橙色薄雾。普通按钮不常亮；主操作、选中和键盘焦点获得局部反射。

按钮材料由四层构成：柔和接触阴影、圆润玻璃面、薄而亮的上缘、受控的暖光。普通内容不加厚重描边。输入框和代码/终端区域使用轻凹表面；成功、错误、忙碌和结果待确认由真实状态驱动。

### 2.2 字体和空间

- 使用 macOS 系统字体及系统中文回退。页面标题 25–28 pt，分区标题 16–18 pt，正文 13–15 pt，说明不低于 11 pt；代码正文 12–13 pt。
- 窗口内容画布 1360×900 pt；标题栏 42 pt，侧栏约 240 pt，页面内容左缘约 x=280 pt，右缘留至少 32 pt。标题、说明和本页主操作在同一视觉组。
- 页面左右边距 40 pt，组间距 24–32 pt，表单行距 12–16 pt。列表行高 48–60 pt；辅助标签不单独套卡片。
- 工作台采用 296 pt 功能目录 + 24 pt 间隔 + 684 pt 详情区。连接首页采用 306 pt 目录 + 36 pt 间隔 + 656 pt 详情区。活动采用 370 pt 列表 + 36 pt 间隔 + 590 pt 详情区。
- 侧栏、搜索框、正文、固定迷你播放器共享同一背景。迷你播放器出现时，正文滚动区留出 72 pt，不盖住内容和焦点。

### 2.3 按钮和点阵

所有按钮沿用 9×9 点阵语汇、圆点颗粒、柔和玻璃边缘与相同的上方光线。操作的形状可以不同；图案按语义设计，保持圆点间距和粗细，不用把图案拉伸成常规字体图标。

| 级别 | 画板尺寸 | 外形和光效 | 使用 |
| --- | --- | --- | --- |
| 主要文本按钮 | 高 42–46 pt，宽度随文案 | 玻璃面稍厚；右上角有短暂暖光；正文文字清晰 | 运行、确认、保存当前步骤 |
| 次要文本按钮 | 高 36–40 pt | 同材质，暖光收敛；与主按钮保持相同边缘质感 | 刷新、复制、导入、筛选 |
| 图标按钮 | 40–48 pt；点击范围至少 40×40 pt | 正方形或圆角方形；图案居中 | 搜索、返回、加号、更多、播放器 |
| 大图标展示 | 96×96 pt | 保留开关旋钮的厚度和宽圆角 | 仅在按钮设计板展示，不强制用于页面 |
| 危险按钮 | 高 36–40 pt | 中性玻璃面加低饱和危险边缘，不持续闪烁 | 删除、撤销配对、轮换身份 |

“运行”图案是完整三角轮廓，底边和尖端连续；“刷新”是单向圆环、只保留一个箭头头部；“搜索”是完整圆环和一段柔和斜柄。这三枚图案统一点距但有各自剪影，不重复落点或出现半格点。其他功能按动作选择运行、音乐、连接、历史、文件、锁定、确认和关闭图案。

| 状态 | 静置设计 | 用户触发后的设计 | 反馈时长目标 |
| --- | --- | --- | --- |
| 运行 | 三角内部有极轻的暖色呼吸；不让整排按钮同步闪动 | 光线向三角收拢，玻璃轻压后回弹 | 120–180 ms |
| 刷新 | 圆环低幅度亮度变化，不自动旋转 | 单向旋转一周；忙碌时由运行状态持续表示 | 点击 180–240 ms；业务忙碌跟随真实状态 |
| 搜索 | 镜片内有微弱暖光，不改变图案位置 | 镜片先亮、柄随后收拢一次 | 120–180 ms |
| 选择 / 导航 | 选中控件留一条低亮暖边；其他项中性 | 点阵和玻璃面短促压合，不移动相邻内容 | 100–160 ms |
| 关闭 / 取消 | 中性玻璃，不持续红光 | 光斑收回，图案轻合拢 | 100–150 ms |
| 危险操作 | 不播放吸引注意的待机动画 | 只表达按下；确认仍遵循原二次确认 | 100–150 ms |

动画共享 `GlassMotion` 时钟，不为每个按钮创建独立计时器。按钮不因装饰动画改变尺寸、布局、业务状态或回调次数。Reduce Motion 开启时停在对应静态造型；键盘焦点与禁用态仍清楚可见。

## 4. 关键流程

1. **找到并运行功能**：全局搜索 → 类型筛选 → 选择能力 → 填写并检查参数 → 选择有效目标 → 确认权限 → 运行 → 查看实际结果。
2. **建立连接**：连接列表 → 添加 → 执行目标选择器 → 适配器配置表单 → 按类型显示对应字段 → 测试 → 只有检查可保存时才启用保存；测试失败时保留填写内容。
3. **管理 Host**：查看真实运行状态 → 生成/复制邀请 → 用户批准设备 → 编辑范围；撤销、拒绝和身份轮换沿用现有危险确认。
4. **控制音乐**：同一音乐会话在播放器页和迷你播放器间延续；按钮显隐条件不变。
5. **查看历史**：按全部、运行中、成功、失败、取消、超时或待确认筛选 → 读运行元数据 → 按当前状态取消、重开或复制诊断；不显示未存储的参数和输出。清空活动、删除连接和撤销配对通过危险操作确认面板表达后果，再沿用原回调。

## 5. 画板到实现的门槛

- 开始一个页面阶段前，先检查对应画板中的布局、文字、按钮和状态；代码未开始时画板就是唯一视觉目标。
- 生产 Profile 截图固定使用与画板相同的 1360×900 pt 逻辑画布和状态样例。窗口尺寸、主题、Fixture 和画板编号写入记录。
- 页面边界、主列宽、对齐点与按钮尺寸偏差不超过 4 pt；主标题、主操作和首屏内容不得被裁切或重叠。中文字体和换行要在 macOS Profile 中复核。
- 对照背景、表面、光向、阴影、玻璃边缘、点阵剪影和文字层级。发现差异先改生产实现以贴合已定画板；若功能契约要求不同，则先更新画板和记录，再实现。
- 完成阶段后保存画板与 Profile 并排截图、相关定向测试、分析结果、提交和远端校验。未经实际画面核对不标为“稿实一致”。
- 后续浅深色与窄窗口复核使用同一套组件和状态，不以单张浅色宽屏截图代表所有页面。

## 6. 不变边界

`glass_theme_switch.dart`、`theme_switch_simulation.dart`、`theme_switch_calibration.dart`、`theme_switch_fitted_calibration.dart` 与主题回调不属于本次重设计。允许调整其外围布局框、字号、页面留白和其他按钮，但不能改主题开关的内部造型或任何交互逻辑。所有按钮重绘只改视觉，不改变操作入口、快捷键、启用条件、回调、权限、Runtime、Host 或音乐会话。

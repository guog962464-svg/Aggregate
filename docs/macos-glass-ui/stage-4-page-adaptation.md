# UI-4：页面布局与按钮位置适配

> 状态：待执行 · 前置：[UI-3](stage-3-coordinated-motion.md)通过 · 后续：[UI-5](stage-5-functional-acceptance.md)

## 目标

按“找到对象 → 输入 → 操作 → 查看结果”的顺序组织页面，复用已经验证的业务逻辑，将新按钮逐页接入。

## 接入顺序与具体流程

### 4A. 外壳、导航与全局搜索

1. 调整 `app/lib/app/app_shell.dart` 与 `app/lib/widgets/page_frame.dart`：合并重复标题/工具栏，顶部保留可见的全局搜索；添加按钮紧邻连接分组。
2. 保留按连接元数据决定首页、上次连接恢复、实时连接变化和能力限制。窄窗保留现有 `<760` 的 Drawer 入口及键盘可达性，避免硬塞完整侧栏。
3. 统一背景和导航图案；选中、焦点与连接状态不能只靠发光或颜色表示。长名称可查看全文。

### 4B. MCP、普通 CLI 与结果

1. 当前 `connection_home_page.dart` 是能力列表，能力点击进入独立 `CapabilityRunPage`。先抽取可复用的参数/执行/结果内容与控制边界，再组成桌面“左目录、右参数、下结果”；独立路由继续复用同一实现。
2. 工具、资源、资源模板、提示、CLI 动作和原生命令分别保留原处理路径。短参数在空间足够时并排，运行位于参数之后；窄窗按输入→运行→结果重排。
3. 结果区紧邻复制/取消/恢复入口。复制状态依据真实可复制内容，运行状态依据事件流；切页、重复选择和运行中返回不重置或复制另一份 RunHandle。
4. 终端保持现有输入、尺寸、中断、选择/复制与会话生命周期，只更换外围操作控件。

### 4C. 音乐播放器与迷你入口

1. 搜索框放在歌曲结果前；当前歌曲信息紧凑，上一首/播放暂停/下一首集中在稳定底部播控组，队列邻近。
2. 复用 `MusicSession`、`MusicPlayerPage`、`MusicMiniPlayer` 的同一个会话；搜索授权、播放确认、账号切换、busy/canPrev/canNext 等条件保持原值。
3. 播放/暂停只 morph 内部图案，不替换整个可聚焦按钮。结果中的播放/加入队列、刷新、停止均使用同一设计体系。
4. 切到其他页面保留播放中的迷你入口；搜索输入、选中歌曲和播放状态不因装饰绘制丢失。不新增假封面、虚假进度或设计稿演示曲目。

### 4D. 管理、活动、设置与弹窗

1. 更新连接列表、检测/诊断、添加配置、目标选择、动作编辑与删除确认。测试通过才可保存、输入变化废弃旧报告等规则完整保留。
2. 全局功能保留搜索/筛选/收藏/来源；活动保留真实状态、脱敏详情、重开、取消与错误重试。危险动作与高频操作留出清楚间隔。
3. 设置按外观、Mac Host、快捷键、本机数据组织。原主题和系统选择成组；父布局调整大小/位置，“跟随系统”按钮使用新材质，背景按 UI-1 接线。主题映射、控件逻辑和可访问语义保持。
4. Host 面板仍经 `platformSections` 注入，启停、邀请、设备权限、身份轮换和撤销绑定真实平台状态。公共组件不能直接导入 `mac_host_settings_panel.dart`。
5. 统一弹窗按钮与图案，但不改变确认边界。打开时聚焦合适字段，关闭后回到触发按钮，弹窗中的快捷键不能穿透到背景运行任务。

每完成 4A～4D 的一组，先检查该组回归和原生截图，再继续下一组；不要一次性替换全部按钮后才查逻辑。

## 交付物与验收

- [ ] **UI-4.1** 搜索可见且 ⌘K 可达；添加靠近连接列表；入口与当前上下文一致，窄窗所有操作仍可访问。
- [ ] **UI-4.2** 参数→运行→结果顺序清楚，复制靠近结果且无内容时不可用；复杂表单、长结果、错误与空态不会挤掉主操作。
- [ ] **UI-4.3** MCP 新组合布局与独立运行路由共享业务实现；同一手势不产生两次调用，资源/提示/终端没有被当作普通工具提交。
- [ ] **UI-4.4** 音乐播控位置稳定，上一首/下一首/停止/队列启用条件不变；mini player 与主页状态一致，不能凭动画完成显示播放成功。
- [ ] **UI-4.5** 管理、活动、设置及所有弹窗的实际按钮均完成操作清单核对；没有遗留风格孤岛或漏掉低频危险操作。
- [ ] **UI-4.6** 原主题任意拖动与太阳/月亮内部变化保持原样；Host、账号与权限流程不因视觉重排减少确认或篡改结果。
- [ ] **UI-4.7** 搜索/表单输入不会因动画重建丢失光标、焦点、滚动位置；切页不销毁应持续的运行或音乐会话。

证据至少覆盖音乐、CLI、MCP、所有功能、连接管理、活动、设置七个设计视图，以及添加、权限和危险确认弹窗。

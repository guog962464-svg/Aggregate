# Android A2：HTTP MCP 实施与验收记录

> 2026-11-11。对应[阶段规划](android-adaptation-plan.md) A2。HTTP MCP 功能与本阶段真机故障路径已验收。

## 实现

- `AndroidRuntimePort` 只声明 `mcp-http`。共享连接向导先做临时 MCP 握手和能力发现，成功后才允许保存；失败不创建连接或凭证。草稿只在内存，十分钟过期，输入变化、关闭、App 退后台或进程重启后失效。
- 连接与偏好写入应用私有 JSON 文件，Bearer Token 写入 Android 安全存储，活动只保留无结果内容的摘要。配置文件损坏时保留备份；启动时清理无连接引用的凭证。保存、删除和排序的持久化操作串行执行；保存中丢弃草稿会回滚新连接和凭证，重复保存明确失败。
- `mcp_dart` Streamable HTTP 支持工具、资源、提示的发现与读取、参数校验、调用、超时和取消。取消已发出的请求报告“远端结果待确认”，连接刷新后可继续使用。搜索、运行和活动使用公共 `RuntimePort` 模型。
- Android 宿主有网络权限。无凭证 HTTP 可以使用明文连接；非本机 HTTP 地址带 Bearer Token 时向导拒绝保存。Android 自动备份已关闭，避免旧配置与安全存储密钥失配。

## 验证

| 场景 | 结果 |
| --- | --- |
| 本机 MCP 服务：预检、丢弃、保存、工具/资源/提示发现与调用、参数拒绝、取消、重启恢复、删除 | Flutter 单元测试与 LGE AN10 真机集成测试通过。 |
| 保存中丢弃、并发保存、重复保存、草稿超时/后台/重启、凭证写入失败和损坏配置 | 契约测试通过；取消中的保存未留下连接或凭证。 |
| 外部 HTTPS MCP：预检、保存、搜索、只读工具调用、Wi-Fi 断开后的不可用状态、恢复后刷新及再次调用、删除 | LGE AN10 真机集成测试通过；测试结束确认 Wi-Fi 已恢复。 |
| 错误 Token、无响应服务、调用中取消 | 同一真机通过；401 报错不含 Token，无响应连接预检超时；取消后的运行标记为结果未知。 |
| Android 全屏向导、系统返回、文件路径入口、键盘安全区 | Widget 测试通过；390 × 844 窄屏及 300 像素键盘区域内，保存按钮保持可见。 |
| Android 与共享界面回归 | `flutter analyze --no-pub` 无问题；Flutter 测试通过。 |

测试设备为 LGE AN10、Android 15/API 35、arm64、4 KB 页。设备没有 SIM，因此网络验收覆盖 Wi-Fi 关闭与恢复，没有验证 Wi-Fi 与蜂窝网络互切。外部服务是公开的只读文档 MCP 端点；没有上传用户项目数据。

## 边界与后续

- Android 当前只开放 HTTP MCP。HTTP 向导无文件字段；CLI 动作清单编辑器和本地结果预览/显示入口均关闭，路径接口在 Android Runtime 明确拒绝。首次开放本地文档功能时，须先实现 Android 系统文档选择器、内容 URI 读取和授权生命周期，不能复用桌面的 `file.path`。
- 真机 TalkBack 朗读顺序、字体放大与场景化手机 UI 在 A7 验收。当前键盘检查是 Widget 的系统 inset 模拟，未宣称真实输入法或 TalkBack 人工验收。
- 本记录不证明 Node/npm、本地 CLI、stdio MCP、Mac Host 或蜂窝网络切换可用。

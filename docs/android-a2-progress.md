# Android A2：HTTP MCP 进展记录

> 2026-11-11。对应[阶段规划](android-adaptation-plan.md) A2。本记录区分已验证的 HTTP MCP 核心闭环与尚未完成的 A2 验收。

## 已实现

- `AndroidRuntimePort` 只声明 `mcp-http`。共享连接向导先做临时 MCP 握手和能力发现，成功后才允许保存；失败不创建连接或凭证。草稿保留在内存，十分钟过期，输入变化、关闭和 App 退后台时丢弃。
- 连接与偏好写入应用私有 JSON 文件，Bearer Token 写入 Android 安全存储，活动只保留无结果内容的摘要。配置文件损坏时保留备份；启动时清理不再被连接引用的凭证。保存与删除采用文件写入及凭证回滚，重复保存会明确失败。
- `mcp_dart` Streamable HTTP 连接支持工具、资源、提示的发现与读取、参数校验、工具调用、超时和取消。取消已发出的请求报告“远端结果待确认”，连接需刷新后再用。未开放本地 CLI、stdio MCP、终端或 Host。
- Android 宿主声明网络权限。无凭证的 HTTP 可使用明文连接；非本机 HTTP 地址若带 Bearer Token，向导拒绝保存。Android 自动备份已关闭，避免恢复旧配置时安全存储密钥失配。

## 仍需完成

- 用外部可达的 HTTP MCP 服务验证移动网络/Wi-Fi 切换、服务无响应、认证失效后恢复及运行中断；目前真机证据只覆盖手机进程内的回环服务。
- 加强“保存中丢弃”并发、草稿过期和真机实际输入法/TalkBack 检查。A2 当前的取消是停止等待并关闭会话，不能证明远端操作已被撤销。
- 审计发现：HTTP 向导没有文件字段；CLI 动作清单编辑器在 Android HTTP-only 能力下不可见，`ResultPanel` 的本地预览/显示按钮也由能力关闭。因此本轮没有 Android 文档导入/导出入口。以后开放需要本地文档的能力时，必须用 Android 系统文档 URI/内容，不传桌面 `file.path`。

A2 仍标记为进行中；本记录不证明 Node/npm、CLI、Host 或外部网络场景可用。

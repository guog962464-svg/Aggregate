# Aggregate macOS 首版：页面规划与 UI 设计

> 版本：v1 · 2026-11-09  
> 适用范围：Aggregate macOS 首版，Flutter/Dart。阶段 1 已实现五页预览骨架、主题与响应式导航；完整真实连接与高保真评审仍在后续阶段实施。  
> 设计目标：把 CLI/MCP 的众多能力压缩为一个清楚、安静、可用键盘操作的工作空间。

## 1. 页面数量与职责

**首版设 5 个页面模板：4 个一级入口 + 1 个任务页面。** 添加连接向导、权限确认和运行详情用弹层或抽屉完成。终端、资源阅读器、提示预览、网易云迷你播放器是“功能运行”中的视图类型，不增加一级导航。

| 页面 | 入口 | 负责什么 | 主要操作 |
| --- | --- | --- | --- |
| 1. 工作台 | 启动默认页；侧栏“工作台”；⌘K | 跨全部连接搜索能力，展示收藏、最近使用与当前可用功能。 | 搜索、筛选、收藏、打开功能。 |
| 2. 功能运行 | 从工作台或连接详情打开 | 展示功能来源、参数表单、运行状态和结果。按能力类型切换工具、资源、提示、CLI 终端或专用视图。 | 填参数、运行、取消、复制/导出结果、返回。 |
| 3. 连接管理 | 侧栏“连接” | 添加 CLI、本地 stdio MCP、远程 HTTP MCP；查看健康状态、能力数量、权限与诊断。 | 添加、编辑、启停、测试连接、查看能力。 |
| 4. 活动记录 | 侧栏“活动” | 按时间查看脱敏调用记录、耗时、结果和错误；帮助定位失败。 | 筛选、查看详情、复制诊断、重新打开功能。 |
| 5. 设置 | 侧栏底部“设置” | 管理外观、快捷键、日志保留、本地数据和应用信息。 | 切换主题、调整偏好、清理记录。 |

### 功能与页面的对应

| 产品能力 | 所在页面或视图 |
| --- | --- |
| 全局能力目录与搜索 | 工作台；⌘K 可在任何页面打开搜索面板。 |
| MCP tool 调用 | 功能运行：schema 表单 + 结果。 |
| MCP resource / resource template | 功能运行：资源阅读器；模板先填变量。 |
| MCP prompt | 功能运行：参数表单 + 内容预览。 |
| 任意 CLI 原生命令、TUI | 功能运行：终端视图。 |
| CLI 结构化动作 | 功能运行：动作表单 + 结果。 |
| 网易云播放控制 | 功能运行的音乐视图；播放中显示可收起的迷你播放器。 |
| 添加、编辑 CLI/MCP | 连接管理；添加向导为弹层。 |
| 授权确认 | 从功能运行或连接管理触发的弹层。 |
| 错误排查 | 连接管理的诊断区、活动记录的详情。 |
| 收藏和最近使用 | 工作台。 |

### 导航关系

~~~mermaid
flowchart LR
  W[工作台] --> R[功能运行]
  C[连接管理] --> R
  R --> W
  R --> C
  A[活动记录] --> R
  S[设置]
  W --> C
  W --> A
  W --> S
~~~

返回动作回到进入功能前的页面与滚动位置。运行中的操作离开页面后继续执行；工作台和活动记录显示其状态。关闭 App 时由 Runtime 按任务策略处理与清理。

## 2. 审美立场：安静的命令工作台

frontend-design 建议先确定与产品内容相关的视觉立场，并让一个元素成为记忆点。Aggregate 的核心不是音乐，也不是“开发者仪表盘”，而是**从许多工具中准确找到并运行一个能力**。因此视觉重心放在横贯窗口的全局搜索与紧凑能力列表；来源、权限和运行状态通过克制但明确的标记表达。

- **主角：**搜索框与结果列表。首次打开即可输入，不用先辨认 CLI 和 MCP 的协议差别。
- **秩序：**文字、留白和细分隔线组织信息；不使用同尺寸卡片墙、装饰性渐变或假仪表盘。
- **个性：**能力名称保持清楚的动词短语；命令与参数使用少量等宽字体，其他文本保持系统字体。
- **动效：**只响应用户操作：搜索面板打开、结果抽屉展开、状态改变。避免滚动入场和持续装饰动画。
- **文案：**“搜索功能”“添加连接”“运行”“连接失败：找不到程序”，使用具体动词和可处理的错误原因。

### 视觉令牌：跟随系统、浅深色配对

颜色是设计提案，实施阶段应在真实 macOS 截图中复核。正文和次要文字的组合已按相对亮度公式初步核算，仍需检查焦点、图标、禁用态和重叠表面。

| 角色 | 浅色 | 深色 | 用法 |
| --- | --- | --- | --- |
| 窗口底色 | #F5F7F8 | #151B20 | 页面背景。 |
| 主表面 | #FFFFFF | #1C252B | 搜索区、主内容和弹层。 |
| 主文字 | #1B2833 | #E8F0F3 | 功能名称、正文。 |
| 次文字 | #546270 | #A8B8C1 | 来源、辅助说明。 |
| 操作强调 | #245F89 | #78B7DF | 运行按钮、选中项、链接。 |
| 焦点轮廓 | #2F7EA9 | #88C8EA | 键盘焦点。 |

已核算的示例对比度：浅色主文字/窗口底色约 14:1，浅色次文字/窗口底色约 5.8:1，白字/浅色强调约 6.8:1；深色主文字/底色约 15:1，深色次文字/底色约 8.5:1。实施时以实际控件背景重新测量。状态色必须同时配文字或图标，不能只靠颜色传意。

### 字体、间距与图标

| 元素 | 规格 |
| --- | --- |
| 中文及普通界面文字 | macOS 系统字体，中文使用系统回退；避免为中文界面强制使用仅覆盖拉丁字形的字体。 |
| 命令、路径、ID、原始输出 | SF Mono 或系统等宽字体；仅在这些内容使用。 |
| 页面标题 / 分组标题 / 正文 / 辅助文字 | 建议 22 / 16 / 13–14 / 12 pt，最终由真实截图与系统字号检验。 |
| 间距 | 4、8、12、16、24、32 pt；组件内、分组间和页面边缘逐级增大。 |
| 图标 | 同一套线性矢量图标；图标旁有可见文字时避免重复朗读。 |
| 分隔与圆角 | 以细分隔线表达层级；输入框和弹层适度圆角，功能列表不做卡片。 |

UI/UX Pro Max 的产品检索把“开发者工具”匹配到极简/高对比风格，并强调可见焦点、表单内错误和键盘可达。它自动给出的 FAQ 落地页布局、荧绿强调色、全篇等宽字体与本产品的桌面工作流和中文内容不匹配，未采用。主题默认跟随 macOS 系统设置，浅深色同时设计。Flutter stack 检索只把路由组织作为候选提示，具体库须按实施时 Flutter 版本核对。

## 3. 页面布局规格

### 3.1 工作台

~~~text
┌─────────────────────────────────────────────────────────────────────┐
│ Aggregate      搜索所有功能…  ⌘K                    ＋ 添加连接     │
├───────────────┬─────────────────────────────────────────────────────┤
│ 工作台        │ 最近使用                                           │
│ 连接          │  搜索歌曲                 网易云 CLI   可用          │
│ 活动          │  查看分支                 Git CLI      可用          │
│               │                                                     │
│ 收藏的连接    │ 收藏的功能                                        │
│ 网易云 CLI    │  运行命令                 终端        本机 Mac      │
│ Git CLI       │                                                     │
│ 项目 MCP      │ 全部功能  [工具] [资源] [提示] [CLI 动作]          │
│               │  功能名称 · 一句话说明       来源             状态   │
│ 设置          │                                                     │
└───────────────┴─────────────────────────────────────────────────────┘
~~~

- 初始状态有连接时显示最近、收藏与可用功能；无连接时只显示“添加第一个 CLI 或 MCP”及两个入口。
- 搜索匹配功能名、描述、连接名和用户别名；相同名称必须显示来源。
- 过滤器按能力类型工作；不可用连接的能力仍可显示，但有明确状态和修复入口。
- 双击或 Enter 打开功能；⌘K 在任何页面聚焦全局搜索。
- 对大型能力列表分批呈现；键盘上下移动高亮项，焦点指示不被浮层遮挡。

### 3.2 功能运行

~~~text
┌─────────────────────────────────────────────────────────────────────┐
│ ‹ 返回  搜索歌曲                                     网易云 CLI     │
├──────────────────────────────────────┬──────────────────────────────┤
│ 参数                                 │ 本次运行                     │
│ 关键词 *                             │ 尚未运行                     │
│ [ 歌名、歌手或关键词            ]     │                              │
│                                      │ 运行后显示进度、结果或错误    │
│                        [运行 ⌘↵]    │                              │
├──────────────────────────────────────┴──────────────────────────────┤
│ 状态  准备就绪          来源：本机 Mac / 已登记的 CLI              │
└─────────────────────────────────────────────────────────────────────┘
~~~

- 左侧参数，右侧结果；窗口窄时结果移动到下方。结果区在提交前也有明确占位。
- MCP tool 与 CLI 动作按 schema 生成控件；字段有可见标签，必填与范围清楚。复杂对象切换 JSON 编辑。
- 失焦后验证字段；运行失败时在字段旁说明原因，多错误时在表单顶部汇总并把键盘焦点移入汇总。
- 运行按钮提交后显示“运行中”与取消；完成后保留输入和输出，方便复制、修改、重新运行。
- 终端视图用同一页面框架替换参数区和结果区；清楚显示当前程序、参数、工作目录与退出码。
- 资源视图提供内容、URI 和复制/保存；提示视图显示参数及生成内容；音乐视图显示歌曲、播放状态和播控。
- 有外部写入或未知副作用时，在运行前显示来源、目标与参数摘要，并按权限策略确认。

### 3.3 连接管理

~~~text
┌─────────────────────────────────────────────────────────────────────┐
│ 连接                                             ＋ 添加连接         │
├────────────────────────┬────────────────────────────────────────────┤
│ 网易云 CLI      可用    │ 网易云 CLI                                  │
│ 项目 MCP        可用    │ 类型：CLI   程序：/…/ncm-cli               │
│ 旧服务          失败    │ 能力：12 项   最近检查：刚刚               │
│                        │ [查看功能] [测试连接] [编辑]                │
│                        │                                            │
│                        │ 诊断：Node、CLI、登录、播放器状态          │
│                        │ 权限：本机控制、外部写入                    │
└────────────────────────┴────────────────────────────────────────────┘
~~~

- 添加连接分三种：本地 CLI、本地 MCP、远程 MCP；第一步先选择类型，再只填写该类型必要字段。
- CLI 选择程序后立即有终端入口；动作清单是后续增强，不阻断基础使用。
- MCP 添加后显示握手和能力发现结果；失败时展示准确阶段与可执行的修复建议。
- 编辑区显示实际程序路径、工作目录或远程 URL；凭证只显示“已配置”，不回显值。
- 权限以连接为单位呈现，并可展开到具体能力；删除连接前说明会停止其运行任务。

### 3.4 活动记录

- 时间倒序列表显示：时间、能力、来源、状态、耗时。默认不展示完整输入或敏感输出。
- 详情面板显示运行 ID、关键事件、退出码或 MCP 错误、脱敏日志及复制诊断。
- 筛选按连接、状态和时间；点击历史项可重新打开对应功能，外部写入不会自动重放。
- 空状态说明“运行功能后，记录会出现在这里”；失败状态给出返回连接诊断的入口。

### 3.5 设置

- **外观：**跟随系统、浅色、深色；预览强调色与焦点状态。
- **操作：**快捷键列表及冲突说明；默认键可见且可恢复。
- **数据：**活动记录保留时长、清理记录、导出脱敏诊断。
- **关于：**版本、运行环境、许可证与更新信息。
- 单连接的程序路径、MCP URL、登录和权限放在连接管理，避免全局设置臃肿。

## 4. 全局组件与状态

### 组件清单

1. 搜索面板：输入、过滤器、结果列表、键盘选择。
2. 连接行：名称、类型、健康状态、能力数量、来源。
3. 能力行：动词名称、简短描述、所属连接、权限/状态。
4. SchemaField：文本、数值、布尔、枚举、文件、对象、数组与 JSON 模式。
5. RunStatus：等待、运行、成功、失败、取消、超时。
6. ResultViewer：纯文本、JSON、表格、图片、文件与原始内容块。
7. TerminalPane：CLI/TUI 输出、输入、尺寸与中断。
8. PermissionDialog：来源、目标、参数摘要、授权范围。
9. DiagnosticPanel：依赖状态、错误原因、修复步骤。

### 关键状态表

| 场景 | 页面反应 |
| --- | --- |
| 首次启动无连接 | 工作台展示两个清楚入口：“添加 CLI”“添加 MCP”。 |
| CLI 路径失效 | 连接显示“找不到程序”；保留配置并提供重新选择路径。 |
| MCP 握手失败 | 显示失败阶段、服务器地址/命令和脱敏错误；提供重试。 |
| 搜索无结果 | 显示关键词和筛选条件；可清除筛选。 |
| 参数有误 | 字段内联错误；不启动进程。 |
| 运行时间较长 | 显示状态与取消按钮；活动记录可追踪。 |
| 结果为空 | 显示“运行成功，未返回内容”，保留原始详情入口。 |
| 权限不足 | 显示缺少的权限和授权操作；不静默重试。 |
| 网易云未登录 | 连接诊断展示登录步骤；播放器不显示虚假播放状态。 |

## 5. 设计与验证流程

### 设计阶段

1. 先用 frontend-design 固定审美立场、色彩/字体/布局原则和页面线框；评审是否真的服务“找功能并运行”。
2. 用 UI/UX Pro Max 的 product、style、ux 与 Flutter stack 查询审视导航、对比度、焦点、表单和响应式行为。检索结果需核对适配性；不把面向网站的落地页结构直接用于桌面 App。
3. 制作浅色与深色的工作台、功能运行、连接管理三个关键页面高保真稿；活动与设置使用相同组件体系。
4. 用真实样本内容替换占位文本：CLI 长路径、MCP 长工具名、复杂 schema、运行失败、中文与英文混排。
5. 实现 Flutter Widget 后在真实 macOS 窗口截图中复核；使用 Flutter 集成测试验证导航、键盘、表单和状态，不把浏览器测试当作原生 App 的主验收。

### UI 验收清单

- [ ] 用户在首次启动时能找到添加连接入口；有连接后能从工作台在两步内打开功能。
- [ ] 五个页面模板职责清楚；终端、资源、提示和音乐视图共享功能运行框架。
- [ ] 800×600、1024×768、1440×900 窗口下无裁切；窄窗口能访问所有操作。
- [ ] 浅深色主题的正文和辅助文字达到目标对比度；状态不只靠颜色。
- [ ] 全部主要操作可用键盘完成，焦点可见、顺序合理且不被抽屉遮挡。
- [ ] 表单有可见标签、内联错误和多错误汇总；失败后保留输入。
- [ ] 长连接名、路径、工具名和输出可查看全文；截断处有展开或提示。
- [ ] 运行、取消、失败、超时、连接断开均有明确反馈。
- [ ] 图标风格统一、无表情符号充当结构性图标；中文字体显示稳定。
- [ ] 动效服从系统减少动态效果设置；结果抽屉等动效不造成内容跳动。

## 7. 技能使用记录与判断

- **frontend-design：**读取了 Anthropic 发布的 SKILL.md。采用“先确定审美立场、令牌和线框，再审查是否落入通用模板”的方法；最终选择以搜索与能力列表为中心的安静工具界面。[^frontend-design]
- **UI/UX Pro Max：**读取其 SKILL.md，并运行设计系统、product/style/ux 与 Flutter stack 检索。开发者工具与 Minimalism/Swiss Style 的匹配、可见焦点、内联错误、文字对比度等结果适用于本项目。设计系统自动返回的 FAQ 落地页模式与本 App 不符，未采用；其荧绿强调和等宽标题也未采用。[^uiux]
- 这两项技能的文件未安装到当前全局技能目录；本次通过其原始仓库读取并运行 UI/UX Pro Max 的本地检索脚本。设计判断已写进本方案，后续实施可重复查询最新版本。

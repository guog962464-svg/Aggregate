# Aggregate macOS 使用手册

本版只在 macOS 上运行。Android 仍是实验目标，没有可供分发的 Release 包；仅开发和验收人员可参考[Android 内部测试指南](android-user-guide.md)，不要将 Debug APK 当作正式产品发布。工作台汇总连接提供的功能；连接页管理 CLI 与 MCP；活动页查看运行状态；设置页管理外观和本机记录。

## 安装预览包

当前 0.3.7 ZIP 是 ad hoc 签名、未公证的预览包，仅供确认来源可信的本人或测试者使用。下载后在终端运行 `shasum -a 256 Aggregate-macOS-stage3-preview-v0.3.7.zip`，结果应为 `f580db0bbccf9c7d05702affbf329c2f789872896e595dbb5c2b30668206a550`。解压后将 `Aggregate.app` 放入“应用程序”并打开。若 macOS 拦截，先尝试打开一次，然后在“系统设置 → 隐私与安全性”中按系统提示选择“仍要打开”；仅在确认文件来源和校验值后这样操作。不要关闭系统的 Gatekeeper。该流程见 [Apple 官方说明](https://support.apple.com/en-gb/102445)。预览包不具备 Developer ID 正式分发所需的签名与公证。

## 添加连接

打开“连接”→“添加连接”，选择适配器并填写所需信息。先点“测试连接”，检查结果后再点“保存连接”；修改任何输入后需要重新测试。

| 类型 | 填写内容 | 发现的功能 |
| --- | --- | --- |
| 网易云音乐 | 官方 `@music163/ncm-cli` 程序绝对路径、开放平台 App ID、PEM Private Key | 内置音乐播放器、账号面板与音乐动作 |
| 自定义 CLI | 程序绝对路径；可选启动参数 JSON 字符串数组、工作目录和动作清单 JSON | 导入清单中的动作；可在详情页“编辑动作”新增或修改 |
| stdio MCP | Server 程序绝对路径、启动参数 JSON 字符串数组；可选工作目录 | Server 报告的工具、资源和提示 |
| HTTP MCP | Streamable HTTP 地址；需要认证时填写 Bearer Token | Server 报告的工具、资源和提示 |

示例：程序路径 `/usr/bin/git`，启动参数 `[]`。CLI 添加后打开连接详情，选“编辑动作”添加一个动作，或导入 [Git 示例清单](../connectors/examples/git-status.json)。HTTP MCP 的 Token 存在 macOS 钥匙串；当前提供静态 Bearer Token，尚无浏览器 OAuth 登录。Token 到期时删除连接并用新 Token 重新添加。

测试自定义 CLI 时会验证程序及清单；测试 MCP 时会完成握手与功能发现。网易云测试先验证本机配置，再分别报告账号登录和搜索接口状态。尚未扫码时可以保存已经通过本机配置测试的连接，随后在播放器内扫码；“配置通过”不代表搜索接口已获服务端授权。连接详情的“测试连接”会重新检查程序或与 MCP 握手。删除连接会移除配置、对应的 App 钥匙串 Token，以及由新版网易云适配器创建的独立账号目录。

## 查找和运行

工作台搜索名称、来源、工具、资源、提示和 CLI 动作。按 `⌘K` 会返回工作台并聚焦内联搜索，输入后结果以可操作按钮列出。打开功能后检查来源、目标和权限，按表单填写参数；`⌘↵` 运行。需要写入或控制本机/外部系统的动作会先显示执行确认。终端型 CLI 可选“在终端运行”，支持键入、调整窗口和中断。运行结果可复制；文件结果只显示路径，点击“预览文件”才读取受限大小的文本或图片，也可点击“在访达中显示”。

活动页保留运行时间、来源和状态，不保存参数或结果正文。设置页可调整保留时长或清空记录。连接顺序和收藏保存在当前用户的 App 数据中。

## 网易云音乐示例

先安装 Node.js、`mpv` 和官方 `@music163/ncm-cli`。在 Aggregate 选“网易云音乐”适配器，App 会查找常见安装目录和 PATH，并核对官方 npm 包身份后自动填写程序绝对路径；也可手动选择或点“自动检测程序”重试。然后填写开放平台 App ID，并粘贴或选择 PEM Private Key。测试时，App 通过官方 CLI 的 `config set` 写入此连接独立的账号目录；临时 PEM 文件随即删除，Aggregate 连接清单不保存私钥正文。测试通过后保存连接，并在播放器内扫码登录。旧版已添加的网易云连接仍沿用原来的 CLI 配置和登录，不会自动迁移。

播放器标题旁的账号按钮显示登录状态。点它可在 App 中扫描白底二维码登录，无需查看终端输出；已登录时可退出，或点“切换账号”先退出再扫码登录另一个账号。切换中途取消或超时会保持未登录，当前版本不保存多个账号供一键切回。退出与切换都要确认，账号变化后会清空旧账号的搜索结果、歌曲状态和本次会话授权。当前 `ncm-cli` 不提供账号身份查询，App 不能显示昵称或证明前后是不同账号，请在手机端核对。若二维码一直未生成或无法扫描，请在 App 内重试并检查网络；普通终端的 `ncm-cli login` 只适用于沿用原账号目录的旧版连接。

打开网易云音乐连接即可进入播放器并搜索歌曲。首次搜索会询问是否允许该 CLI 执行搜索；允许后，本次 App 会话中同一连接的后续搜索可直接执行，切换连接或重启 App 后需重新确认。首次播放或播控另行确认。结果会标明歌曲可播状态；点击可播歌曲后，播放器会轮询真实状态。队列已有歌曲时，“加入下一首”可将另一首歌排在当前歌曲后面。高级动作仍可从“所有功能”进入。`ncm-cli` 的后台守护进程有时在播放开始时超时，界面会先显示“正在确认”；App 不会自动重发结果不明的播放命令，以读取到的状态为准。切歌会核对队列位置和播放状态；若始终无法确认，按[故障排查](troubleshooting.md)处理。开发用完整播放探针会将音量设为 50 并在结束时停止播放。

## 本机数据和限制

连接配置、动作清单、偏好和活动记录保存在当前用户目录；HTTP MCP Token 保存在钥匙串。运行外部 CLI/MCP 时，目标程序或服务可以按自身权限访问数据或网络，请核对来源与执行确认内容。当前版本只支持 macOS；其他端的公共契约已预留，但尚未发布。当前无法取得 Developer ID，正式分发暂缓。

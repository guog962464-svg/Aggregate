更新：2026-11-10。当前交付目标为 **这台 Apple Silicon Mac 上的 macOS 预览版**，最新包为 0.3.7。用户当前无法取得 Developer ID，因此本版不以正式签名、公证或对外分发为验收目标。Intel Mac、macOS 12 和独立用户的兼容矩阵暂缓；搜索结果已进入开启 VoiceOver 的原生辅助功能树。用户已通过 Aggregate App 人工验收网易云稳定播放、播控与实际出声；早先自动探针失败保留为回归风险。逐项状态见[阶段 2/3 本机验收](phase23-acceptance.md)。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 通用平台 | CLI 动作编辑、导入/导出与参数预览；stdio/HTTP MCP 工具、资源、提示；PTY 终端；收藏、最近使用、连接排序、⌘K 搜索、活动保留与清空。 |
| 连接诊断 | 缺失程序/权限、HTTP 401/403、网络/超时、MCP 响应或协议不兼容分类提示；诊断不回显 Token、请求头或服务端正文。HTTP 认证仍为静态 Bearer Token。 |
| 结果与恢复 | 文件结果需显式点击才预览，限制格式和大小，可在访达定位；资源/提示显示耗时；损坏配置备份为 `.damaged-*` 后恢复默认并在工作台提示；写入失败不阻塞后续保存。 |
| 稳定性 | CLI 长任务取消、超时、重复调用、异常退出、超大输出；打包 App 内的普通 CLI 通过独立进程组清理子进程；MCP 断线后有限重连且不重放未知结果；原生 Keychain 跨进程读写删除。 |
| 网易云 | 检查 Node、npm、mpv、`ncm-cli` 与账号接口；仅在本机 npm 包名及 `bin` 入口与 `@music163/ncm-cli` 匹配时自动启用专用动作，同名其他程序仍作为普通 CLI。搜索结果标明可播状态；队列已有歌曲时可从结果中“加入下一首”；搜索、播放、暂停、继续、停止、切歌、音量、状态动作接入同一 RuntimePort。播放响应不明时不自动重放命令，只轮询真实状态；`playing` 但队列为空视为待确认，播放控制等待状态查询后更新 UI，切歌核对队列位置与 `playing`。单曲或队列边界不显示无效切歌按钮。 |
| 界面 | 5 个页面模板、浅深色主题、窄/宽布局、表单错误提示、键盘搜索与运行快捷键、音乐搜索结果和迷你播放器。 |

公共 Flutter/Dart 契约与 Widget 不依赖 macOS 系统 API；进程、文件与钥匙串实现留在 `app/lib/platform/macos/`。网易云只是一个可选 CLI 连接器。

## 未完成的预览验收与后续事项

3. **后续兼容矩阵**：用户决定先打磨当前 Mac。Intel 实机、macOS 12 实机、独立用户首次安装和旧版覆盖升级暂不计入本轮预览通过门槛；当前已在本机 arm64 的隔离 HOME 做首次启动、旧配置读取，并检查打包后的双架构切片。
